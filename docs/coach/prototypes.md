## 怎么用

1. **按原型练，不按页刷。** 首轮每个原型做 10–15 道（挑计算题、带图的、真题风格）。
2. 优先级：**A 必拿 → B 争取 → C 边坡 → D 基坑 → E 低频**。
3. 页码：解析 = 案例习题集（上/中/下），空白 = 对应空白册。从空白册做，用解析册对。
4. 做完在该节打勾，错题按 `不会/算错/规范错/审题错` 归类。

## 首轮选题规则

- 优先计算题，跳过纯概念题
- 优先带查表的题（考试原样）
- 同一子考点连续 3 道做对即跳到下一个
- 单题超 10 分钟没思路：记下，跳过
- 每原型做完，闭卷写 3–6 步解题流程，写不出的就是坑
