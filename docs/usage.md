# 岩土学习驾驶舱 · 使用说明

> App 里随时能看：顶部「今日」→「完整说明」，或直接打开 `http://<电脑IP>:8000/?tab=guide`。

## 这套系统怎么运作

```
打印今天的卷（App 记住复习/新题清单）
  ↓ 做完核对：默认都算对，只标没做对的题和错因
自动归档
  ├ 错题 → 错题本（带错因和照片）
  ├ 复习题 → 自动排下次（7 / 15 / 30 天）
  └ 新题 → 今日练习总量（不用手填四个数）
```

- **今日卷是 App 打印的**：它知道哪些是复习、哪些是新题，核对时不用再选题号。
- **不是 App 打印的纸面**：用「拍题」拍题号 → 勾选 → 记错；一次拍一页，不用一题一题录。
- **复习在 App 里做**：点「没做对」自动记；纸面复习也要回 App 核对一次。
- **每天新题不是拍脑袋**：阶段周目标（现在 20 题/周）÷ 剩余天数，再受每天约 94 分钟
  的时间预算限制；题目按未完成原型从题库里选。
- **四个数不用手填**：今日卷核对时按每题结果自动算；只有没打印、自己另做的练习，
  才去计划页手动记一次。

## 每天怎么用（只有两步）

1. **打印今天的卷**。首页「今天的卷」→「打印今天的卷」：一份 PDF 同时装
   今天要复习的错题和今天的新题，页面上会写清题数和预计分钟。
   没时间就点下面的 30 / 60 分钟短卷：先保复习，剩下的顺延。
2. **做完核对**。回首页 →「做完核对（N 题）」：
   - 默认所有题都算「对」。只把没做对的题点成「错」，再点错因
     （不会 / 算错 / 规范错 / 审题错）。
   - 「没做」「超时」需要时点一下；超时是速度标记，不算错因。
   - 可以拍一张卷面，照片会随错题保存。
   - 保存后自动归档：错题入本、复习排期、练习总量都自动写，**不用填四个数**。

**隔天才核对也行**：打印的卷不会过了零点就消失。只要还没核对，首页会一直显示
「还没核对的卷 · 11/17」，点进去补标错题即可；核对后按实际完成日重新排复习。

**卡住时问 AI（可选）**：复习页看完答案后、错题详情、查题查看器都有「问 AI」；
它只讲这一题，不判分、不改排期。见下面「问 AI」。

**没打印的日子**：首页点「直接在 App 里复习」。
**新错题**：底部「拍题」→ 拍题号 → 勾选 → 记错；或从手写面板的「拍新错题」进。

### 单题手写照片（可选）

三个入口，存的是同一个位置——这道题的「过程照片」：

- **复习页每题下面的「拍手写过程」**：边评边拍，点「做对 / 没做对」时一起保存；
- **首页「补单题手写」（任务单里也有）**：事后补，拍完立即保存；
- **今日卷核对里的「拍卷面」**：整张卷一张照片，保存时随错题挂上，不用逐题拍。

同一题再拍会覆盖上一张；错题详情和复习里都能回看。

### 问 AI

- **入口**：复习页「看答案」之后、错题详情、查题查看器；也可以直接用
  `/?qid=A2025-A-9&ask=1` 打开。复习页在答案出现前不显示，避免剧透。
- **它会自动带**：这题的题干 OCR、官方解析 OCR、匹配到的规范条文（条号 + 原文页）。
  只带这一题，不带整本错题本；默认不发原图，也不发你的备注/照片。
- **回答怎么读**：先给结论，再给依据（解析哪一步 / 哪条规范），再指出容易混的点，
  最后回到本题取法。回答里的条号会在本机规范索引里复核，查不到会标「未核对」；
  整个回答标「AI 解读」，**不判分、不改复习排期、不自动打错因**。
- **存哪**：问答按题号存在 `data/`，随备份；同一问题 30 天内走缓存，不重复花钱。
- **费用**：DeepSeek 一问约 1–2 分钱；默认每天 20 次上限，超了会直接提示。
  key 在电脑的 `data/llm.json`，不进 git、不进备份。
- **语音**：手机直接点键盘上的 🎤 说话（微信/Chrome/Safari 都行）。网页里「按住说话」
  需要 HTTPS，等 Tailscale 版再加。
- **限制**：DeepSeek 是文本模型，题图先在电脑上 OCR 成文字再发；图里的层厚/尺寸
  如果 OCR 不清楚，它会以解析的取法为准。AI 仍可能讲错，以解析和规范原文为准。

### 拍新错题

发现自己做错时：底部「拍题」→ 拍题号 → 核对题干/解析 → 勾错因 → 存入错题本。
题号认错时选手动输入。

- 能认两种印法：习题册的 `3-11`，和真题/模拟卷上的 `A2025-A-7`、`K2025-P-68`、
  `M2-13`（App 打印出来的卷面就印这种号）。真题号自带年份场次，不用先切当前册。
- 拍完一页直接点「拍下一张」，不用先退回首页；查看器里的「拍下一张」也一样。
- 手机返回手势 / 左上「‹」按 **查看器 → 候选 → 拍题首页** 逐级后退，
  照片和勾选都还在；首页会出现「继续上次识别」，可一键回到候选，不用重拍。
- 页面顶部的日期不会再被当成题号候选。
- 原版真题书页上只印 `7.` 这种题序；没有 `A2025-A-7` 字样时，App 无法判断是
  哪一年哪一场，需要手动输入（或在 App 里打印成卷后再拍）。
- 错因只有四类：**不会 / 算错 / 规范错 / 审题错**。**超时不算错因**：
  做错且超时仍按真实原因选；没时间做完可以留空，场次照常记「超时」，
  速度训练走「限时拆解」。

### 有余力再做

有额外时间再做**训练**（限时拆解 / 认题卡）和**规范伴读**；这两项是选做，
复习、新题、台账才是每天的基本盘。

伴读页里点规范图（或「全屏精读」）进入精读：左边是要点和目录，右边是标注版原页；
默认按宽度铺满，`整页` 看全貌，`+ / −` 缩放，拖动平移，`← / →` 翻页，`Esc` 退出。
手机上点顶部「要点」打开左栏。

## 每周怎么用（约 30 分钟）

- 看「数据 → 周报」：练习四个数、计划达成、新增错题/掌握、下一周的下一步。
- 把本周没做完的任务卷打印出来，或直接打「本周任务卷」。
- 周计划落后时，先清复习积压，再减新题；连续两周落后 >20% 会提示减量。

## 打印怎么用

- 首页「今天的卷」= **今日卷**：今天要复习的错题 + 今天的新题，一份出完；
  顶部「打印」按钮有更多范围。
- 卷面规则：**题面在前，答案单独成页**；第一次做的时候不要翻后面的答案。
- 封面可选任务单 + 结果回填格：`qid  对□ 错□ 放弃□ 超时□`，
  做完照格子录回 App。
- **文件名**形如 `岩土-今日卷-20261104-153012.pdf`：
  卷名 + 生成时间，每份都不一样，不会互相覆盖。页面页脚也会印同样的时间。
- 常用范围：
  - 今日全套：今天的复习队列 + 今天的新题（每天一键就这份）。
  - 今日复习卷：只打复习队列（冻结队列，不是剩余题）。
  - 本周任务卷：按本周未完成原型选最多 30 题。
  - 错题卷：按错题本当前筛选（册/错因/章节/未掌握/最近 N 天）。
  - 自选：查题查看器、错题详情、训练结束页的「打印本组」。

## 出差 / 一周的量

1. 顶部「打印」→ **未来 N 天复习包**，选 7 天（也可 3/5 天）。
2. App 按**当前排期**把未来每一天要复习的题排好，末尾再附**本周新题**
   （按未完成原型选，最多 30 题，和复习去重）：
   - 每天一页小封面（日期、题数、预计分钟、当天 qid 回填格）；
   - 当天题目紧跟其后；新题放在「本周任务 · 未完成原型」一节；
   - 所有答案统一封在整包的最后一页之后。
3. 一天撕一份，答案别提前翻。回来在 App 里逐题记结果，排期会自动续上。

**注意**：周包是预测——今天做对/做错会改变后面几天的到期日。周包最多排 100 题
（新题先占额度），超出的部分留在下一次打印。没有到期题的日子不会出现在包里。

## 手机 / 电脑

- 电脑双击 `start.bat`：后台启动服务、打开电脑浏览器、弹出二维码。
- 手机和电脑连同一个 Wi-Fi，扫码进入；浏览器菜单「添加到主屏幕」，用起来像 App。
- 笔记本换网络后地址会变，重跑 `start.bat` 扫新二维码。
- 开机自启：`py -3 tools/autostart.py --install`；取消用 `--remove`。
- 停止服务：`stop.bat`。

## 数据与备份

- 所有用户数据在 `data/`（`wrongbook.db` + 照片 + 设置 + 周报 + 备份），题库索引只读。
- 「设置 → 备份」导出单 zip（数据库 + 附件）；换电脑先恢复再继续。
- 照片默认每题保留最近 2 张过程照；设置页可清理，清理前自动备份。

## 常见问题

**今天任务单显示 0 题 / 复习空？**
今天没有到期题。可以加练一组认题卡，或记一道新错题，都算学习。

**复习明明做完了，任务单没打勾？**
纸面卷要在首页「做完核对」里保存才算；只在纸上做、只拍错题，不算复习记录。

**手机打开还是旧页面？**
先确认手机和电脑连同一个 Wi-Fi。重跑一次桌面「岩土 · 扫码启动」，
**重新扫新生成的二维码**：二维码现在带版本号（`?v=…`），每次页面更新都会变，
微信内置浏览器就不会再拿旧快照。已经打开的旧页面请关掉重进。
主屏幕 App 可以上滑彻底关掉再打开；更新到新版后，回到前台会自动检查版本并刷新。
设置页最下面会显示页面版本，可用来确认。

**错题要一题一题录吗？**
不用。App 打印的卷在「做完核对」时自动入本；别处做的纸卷用「拍题」
一次拍一页，识别后勾选、点「记错」整页入本。

**四个数还要自己填吗？**
今日卷不用：核对时按每题结果自动算。只有没打印、自己另做的练习，
才去计划页「记一次练习」手动填。

**今天题太多/没时间做怎么办？**
先看首页第 1 步写的「约多少分钟」；超过今天的可投入时间时，直接用
卡片底下的 30 / 60 分钟短卷。短卷先保复习（复习日期会滚，优先清），
没做完的复习自动顺延，新题留在周计划里，不会消失。实在没时间就只做复习或只记四个数。

**周包里的题和真正到期的不一致？**
排期在答题后会变。周包只在出发前打印一次时是准的；回来录结果后以 App 为准。

**打印下载了两个同名文件？**
不会。文件名带秒级时间戳（`-YYYYMMDD-HHMMSS`），每次都不一样。
