# 岩土学习驾驶舱 · 使用说明

> App 里随时能看：顶部「今日」→「完整说明」，或直接打开 `http://<电脑IP>:8000/?tab=guide`。

## 每天怎么用（基本盘 20–40 分钟，训练/伴读另算）

1. **打开 App**。第一次打开会自动弹出「今日任务单」，之后点顶部「今日」再看。
   任务单里的每一项都来自当天的真实记录，做完会自动打勾。
2. **错题复习**（页面上写「错题复习 N 题」）。
   按到期 → 新错 → 顽固排好，一天最多 20 题；知识题两按钮，案例题按过程点选。
3. **新题练习**。任务单按本周目标除以剩余天数，给今天的分量；
   做完在「数据 → 计划」记四个数：作答 / 做对 / 放弃 / 超时。
   这四个数决定周计划和纠偏建议，不能省。
4. **拍新错题**（发现自己做错时）。底部「拍照查题」→ 拍题号 → 核对题干/解析 →
   勾错因 → 存入错题本。题号认错时选手动输入。
5. 有额外时间再做任务单里的**训练**（限时拆解 / 认题卡）和**规范伴读**。
   这两项是选做；复习、新题、台账是每天的基本盘。

## 每周怎么用（约 30 分钟）

- 看「数据 → 周报」：练习四个数、计划达成、新增错题/掌握、下一周的下一步。
- 把本周没做完的任务卷打印出来，或直接打「本周任务卷」。
- 周计划落后时，先清复习积压，再减新题；连续两周落后 >20% 会提示减量。

## 打印怎么用

- 顶部「打印」按钮随时可用；首页「打印出来做」四格是快捷入口。
- 卷面规则：**题面在前，答案单独成页**；第一次做的时候不要翻后面的答案。
- 封面可选任务单 + 结果回填格：`qid  对□ 错□ 放弃□ 超时□`，
  做完照格子录回 App。
- **文件名**形如 `岩土-今日复习卷-20261104-153012.pdf`：
  卷名 + 生成时间，每份都不一样，不会互相覆盖。页面页脚也会印同样的时间。
- 常用范围：
  - 今日复习卷：今天队列里的全部题（冻结队列，不是剩余题）。
  - 本周任务卷：按本周未完成原型选最多 30 题。
  - 错题卷：按错题本当前筛选（册/错因/章节/未掌握/最近 N 天）。
  - 自选：查题查看器、错题详情、训练结束页的「打印本组」。

## 出差 / 一周的量

1. 顶部「打印」→ **未来 N 天复习包**，选 7 天（也可 3/5 天）。
2. App 按**当前排期**把未来每一天要复习的题排好，末尾再附**本周新题**
   （按未完成原型选，最多 30 题，和复习去重）：
   - 每天一页小封面（日期、题数、预计分钟、当天 qid 回填格）；
   - 当天题目紧跟其后；新题放在「本周任务 · 未完成原型」一节；
   - 所有答案统一封在整包的最后一页之后。
3. 一天撕一份，答案别提前翻。回来在 App 里逐题记结果，排期会自动续上。

**注意**：周包是预测——今天做对/做错会改变后面几天的到期日。周包最多排 100 题
（新题先占额度），超出的部分留在下一次打印。没有到期题的日子不会出现在包里。

## 手机 / 电脑

- 电脑双击 `start.bat`：后台启动服务、打开电脑浏览器、弹出二维码。
- 手机和电脑连同一个 Wi-Fi，扫码进入；浏览器菜单「添加到主屏幕」，用起来像 App。
- 笔记本换网络后地址会变，重跑 `start.bat` 扫新二维码。
- 开机自启：`py -3 tools/autostart.py --install`；取消用 `--remove`。
- 停止服务：`stop.bat`。

## 数据与备份

- 所有用户数据在 `data/`（`wrongbook.db` + 照片 + 设置 + 周报 + 备份），题库索引只读。
- 「设置 → 备份」导出单 zip（数据库 + 附件）；换电脑先恢复再继续。
- 照片默认每题保留最近 2 张过程照；设置页可清理，清理前自动备份。

## 常见问题

**今天任务单显示 0 题 / 复习空？**
今天没有到期题。可以加练一组认题卡，或记一道新错题，都算学习。

**复习明明做完了，任务单没打勾？**
任务按当天 `review_log` 记录计数：用 App 里的复习流程记结果才算。
打印出来在纸上做，需要回到 App 逐题记。

**周包里的题和真正到期的不一致？**
排期在答题后会变。周包只在出发前打印一次时是准的；回来录结果后以 App 为准。

**打印下载了两个同名文件？**
不会。文件名带秒级时间戳（`-YYYYMMDD-HHMMSS`），每次都不一样。
