# 岩土错题本 v1 · 构想大纲

状态：构想稿（未写代码） · 2026-10-31
北极星不变：**拍题号 → 秒出解析 → 自动归类错因**，服务 2027 注册岩土专业考试。

---

## 0. v1 成功标准

用真实备考动作验收，而不是用功能清单验收：

1. 单道错题：手机拍一张即入本，**不用改名、不用输题号**；一套 25 题模拟卷 **3 分钟内**录完。
2. 任意已知题号 → 题干 + 解析，**≤ 2 次点击、≤ 2 秒**。
3. 错题可按 册 / 章 / 错因 / 时间 过滤，能进入「只给题、后给答案」的重做模式。
4. 全程本地：无账号、无云、断网可用（在同一局域网内）。
5. 用户数据只有一个 SQLite 文件 + 附件目录，可一键备份。
6. 错题可按筛选条件导出 A4 打印卷，文字与公式像原书一样清楚，并留出手写空间。
7. 每次练习结束有「具体数据 + 下一步 + 一句真正的鼓励」，不是空泛表扬。
8. 复习单题操作 ≤ 2 次点击（展开答案 + 会/不会），不手动排期、不手动选题。
9. 打印从筛选到生成默认 PDF ≤ 2 次点击。

## 1. 用户与场景

单用户（_ming），桌面 + 手机，纸笔做题为主，App 是**伴读工具**，不是刷题平台。

三个高频动作：

| 场景 | 动作 | 对产品的要求 |
|---|---|---|
| 遇到错题 | 手机拍一张 → 自动入本 | 不命名、不选册、可撤销 |
| 做完几题，对答案 | 找题号 → 看解析 → 判对错 | 定位快、答案秒出 |
| 做完一套 | 批量标错题 | 拍一页能一次录多条 |
| 周期性复习 | 只看错题，重做，标掌握 | 答案默认隐藏、能按章/错因筛 |

核心原则：**用户只做三件事——拍、做、对答案**；命名、归类、排期、统计、排版都由系统接管。

明确不服务的场景：通勤刷题（需要电子书，不做）、多人共享、手机端学习新知识。

## 2. 资产盘点

### 已经有的

- 12 本扫描 PDF，**5,120 页，约 4.9 GB**，纯图像、无文字层。
- `index/lookup.json`：**8,826 个题目标识**
  - 章-题 5,431（案例 C 2,501 + 知识 Z 2,930）
  - 真题 2,571（案例 A 751 + 知识 K 1,820）
  - 模拟 824（M 族，33 套）
- 9 本章-题书的 JSONL 带**题号检测框**（pixel bbox），可直接做题内裁切。
- 一套已验证的提取工具链（RapidOCR 两阶段、几何过滤、断点续跑）。
- 外部规范库（_ming 已有，`E:\其他文件\2025YT\3注册岩土全套电子版规范（2024大纲）`）：
  50 本规范 +《工程地质手册》+ 2 张区划图，共 51 个 PDF、约 1.3 GB；
  部分带文字层、部分为扫描件。**v1 不依赖、不复制**；
  v1.5 起做「解析里引用的规范条文可跳转」，详见 `docs/standards-knowledge.md`。
- **18 张真实错题照片**（`拍照错题/`）：4096×3072 手机翻拍，含完整题干、手写过程、红笔批注；
  文件名即题号，`错` 后缀表示错题，`4-12 4-13错.jpg` 这种一图多题也存在。
  这是**现成的错题种子数据**，也是 OCR / 裁切 / 导入流程的真实验收集。
- **12 本 PDF 前置目录页**：用于 OCR 出章节名，不需要另拍目录照片。

### 会直接影响实现的五个事实

1. **页码是 1-based**，PyMuPDF 取页要 `page - 1`。这是落地时最容易踩的 off-by-one。
2. 裸题号 `1-58` 跨族撞号，必须带族前缀：`C` / `Z` / `A` / `K` / `M`。
3. **答案形态有三种**，展示逻辑必须分开处理：

   | 族 | 题本 | 解析来源 | 形态 |
   |---|---|---|---|
   | C 案例 2,491 | 空白习题 4 册 | 案例习题集 3 册 | 题与解答分属两本书（对照本） |
   | Z 知识 2,946 | 知识习题册 上/下 | 同页 | 题目 + 【答案】+【解析】**自包含在同一页** |
   | M/A/K 3,395 | 模拟/真题 | 同书后置答案区 | 题区与答案区分离 |

4. `lookup.json` 只给**页码**，不给「题在页内哪一段」；真题/模拟 1,064 页还没有题号框。
5. `lookup.json` 没有标注每本书的角色（题本 / 答案本），需要在应用层补一张 **12 行的书目登记表**。

### M0 要补的缺口

- [ ] 书目登记表：12 本书 → 族、角色、显示名、PDF 路径
- [ ] 书目指纹表：12 本的页眉/标题/版式特征，用于照片自动识别册别
- [ ] 用 18 张旧照片建立「无文件名识别」测试集（文件名只作为 ground truth）
- [ ] 真题 + 模拟的页内题号框 / 答案框（1,064 页，跑一次标记 OCR）
- [ ] 章节名表：从 12 本 PDF 前置目录页 OCR 出约 40 条章名，与 qid 章号对齐
- [ ] 压缩后的 PDF 工作副本（见附录 A）
- [ ] 100 题随机裁切抽检（三族各 30+）

## 3. 核心循环

```
书桌前做题，遇到错题
   │
   ├─ 拍错题照片（不改名） → 识别题号 + 页眉册别 ┐
   ├─ 拍整页 → 识别本页所有题号 ──────────────────┤→ 确认/点选（通常 0–1 次）
   └─ 手输题号（键盘兜底） ───────────────────────┘
                                  │
                     写入错题本（SQLite，照片作为附件）
                                  │
              ┌───────────────────┴───────────────────┐
              │                                       │
        查答案模式（默认展开解析）            复习模式（默认隐藏解析）
        题干图 + 解析图 + 手写照片             题干图 → 自己重做 → 展开解析 → 标掌握
```

## 4. 功能蓝图

### P0 — v1 必须有

**F1 上下文与定位（拍照即录是主路径）**

- **拍照即录**：手机直接拍错题 → 上传 → 本地 OCR 识别印刷题号与页眉册别 → 自动建错题记录；
  **不改文件名、不输入题号**。
- 唯一高置信题号时直接入库，底部显示 5 秒「已记 3-17 · 撤销」；
  多题或低置信时列出候选，点一下即完成，不瞎猜。
- 册别：记住当前册；能从页眉/标题识别时自动切换，识别不到就沿用当前册；
  同号跨族（`C1-58` / `Z1-58`）时列出两个候选。
- **连拍/批量上传**：一次拍多道错题，后台排队识别；高置信自动入库，
  低置信集中进「待确认」列表，事后再点，不打断做题。
- 拍整页：识别本页所有题号，勾选做错的题（一套/一页批量）。
- 可选：只拍题号特写，识别更快；拍整题也能用。
- 手输题号：键盘兜底，支持 `C1-58`、`Z3-12`、`M2-13`、`A2015-P-19`、`K2019-A-70` 简写。
- 只识别题号与册别，不识别题干；题干仍用原图。

**F2 看题与解析**

- 题干裁图：题号行上沿 → 下个题号行上沿（页尾则到页面底部）。
- 解析裁图按族走三种来源（见上表）；C 族从案例习题集对应题号处裁。
- 默认查答案模式直接展示解析；复习模式默认折叠。
- 跨页题：裁到页尾，提供「下一页 / 整页」逃生口。
- 双指缩放；记住每题上次的滚动位置。
- Z 族自包含答案：先整段展示；复习时按 【答案】 行做遮罩拆分（M3）。

**F3 错题记录**

- 一键「错了」，或对本页识别结果批量勾选。
- L1 知识点：自动（族 + 章），显示章名。
- L2 错因：只保留 **4 个粗标签**，支持「一批题统一打标」：
  - `不会`：概念、公式、原理没掌握
  - `算错`：计算、代数、单位换算
  - `规范错`：条文记错/查错、查表与取值错
  - `审题错`：看漏条件、理解偏差、掉陷阱
  - 「时间不够」只记在场次上，不挂单题
- L3 个人笔记：一句话 + 可选手写过程照片。
- 标签不是必填：不选就是「未分类」，允许做完一组后批量补，不在做题中途拦人。
- 记录时间、来源册/套、题号、重做次数。

**F4 错题本**

- 列表 + 按章 / 按错因 / 按时间过滤；自动分组，不需要手动建文件夹或标签树。
- 单题详情：**官方解析 + 自己的手写过程照片**（并排/切换）、历史记录、笔记。
- 掌握状态：未掌握 / 再练 / 已掌握。
- **存量照片导入（仅旧照片，一次性）**：新流程拍照即录、文件名无关；旧照片才用文件名当提示。
  扫描 `拍照错题/`，解析文件名里的题号（支持 `错` 后缀、一图多题、空格），
  按当前册建立错题，照片作为「手写过程」附件；按文件哈希去重，重复导入不产生重复记录。
  导入前给预览：文件名 → 题号、缩略图、默认全选为错题（可逐条取消）。
- 照片附件统一 EXIF 转正 + 生成缩略图，原图保留，不覆盖。
- 单文件备份（SQLite + 附件打包）。

### P1 — v1.5（F5 / F6 / F7 已确认核心需求，M3 交付）

- **F5 今日复习（零决策）**：打开 App 只有一个大按钮「今日复习（N）」；系统自动组卷：
  到期错题 + 最近新错 + 少量顽固题，按 2–3 个章节交错；用户不选题、不排期。
- 单题流：题干图 → 自己先做/回忆（解析默认不展开）→ 点一下看解析 →
  「没做对 / 做对了」两个按钮 → 自动下一题；标签可选，不选不拦路。
  单题操作 ≤ 2 次点击（不含思考/作答）；也支持左右滑（右=做对，左=没做对），误操作可撤销。
- 自动保存进度；首页显示今日题量与预计用时，回来能接着上次继续。
- **F7 轻量间隔**：没做对缩短间隔（1/3 天），做对拉长（7/15/30 天）；
  连续 2 次做对且间隔 ≥ 7 天才算「已掌握」；错 ≥ 3 次标「顽固错题」，
  提示回书/回规范，而不是继续机械刷。
- 每日上限 20 题；积压时按「到期 + 顽固 + 章覆盖」排序，不让队列变成负担；
  状态差时给「今日三题」。
- 进阶筛选（按章/错因）保留，但默认不用；不做复杂 SRS 算法。
- **F6 导出打印卷**（已确认需要）：按筛选条件生成 A4 PDF，题面页与答案页分离；
  裁切按原尺寸或 2-up 排版，不强行放大到整页宽度，保证清晰。详见附录 B。
  默认一键：今日复习/最近错题/当前筛选 → 默认版式（2-up + 留白 + 答案分离）；
  高级选项折叠。

### P2 — v2

- **F8 答案页按需 OCR**：只对已加入错题本的题做 OCR，抽取 `《规范名》+ 条文号` 与点评关键词，
  给出错因候选，人工确认。正则可覆盖「根据《建筑地基基础设计规范》5.2.1」这类结构，不引入云端 AI。
- **F9 规范 / 知识点视角**：例如「地基承载力」相关错题聚合。
- 详细草案：`docs/standards-knowledge.md`
  （依据抽取、规范错定位训练、章节知识卡、考前 one-pager）。
- **F10 全库全文搜索**：需要全量 OCR，成本高，暂不做。

### 学习陪伴（跨模块，从 M1 开始逐步加）

- **零摩擦采集**：拍完即录，不命名、不选册（能自动识别时）；采集越省事，错题本越能坚持。
- **每次练习结束**：一屏数据（本次多少题、错在哪、最值钱的一道）+ 下一步动作 + 一句基于事实的鼓励。
- **周报**：覆盖章节、错因分布、复习完成率、本周清掉的旧错题；只陈述与建议，不制造焦虑。
- **错题复活**：标记已掌握的错题，隔 7 天回到队列；清掉时给小庆祝。
- **今日三题**：状态差的日子给最小任务，避免断档。
- 考试倒计时、周目标可配置；不比较他人、不做排行榜、不刷屏。
- 鼓励文案用**本地模板 + 真实数据**填充，不调用云端 AI，不空泛。

## 5. 关键设计决策

| # | 决策 | 理由 | 代价 |
|---|---|---|---|
| D1 | **上下文优先，不猜书**：先选册/套，再拍题号 | 裸题号跨族/跨套必然歧义；识别页眉卷别成本高且脆 | 每换一本书多点一次（用最近使用/收藏抵消） |
| D2 | **以图像裁切为唯一内容形态**，不做全文 OCR | 题干有公式/插图，文字化会失真；现有资产就是页图 | 不能全文搜索 |
| D3 | **自动归因分层**：只有 L1 真自动 | 错因是个人化的，纯自动判定不可靠；先保证录入快 | L2 需要手点标签 |
| D4 | **手机优先，PC 同网页** | 书桌场景拍照用手机；PC 粘贴截图 + 键盘更快 | 不做原生 App / 小程序 |
| D5 | **题目目录只读，用户数据独立** | 重建索引不碰用户数据；备份只备份小库 | 需要启动时加载 1.4MB JSON |
| D6 | **裁切按需 + 磁盘缓存** | 不预生成 8,826 张图；缓存命中后秒出 | 首次裁切 ~0.2s |
| D7 | **打印质量优先**：原生分辨率 + 留白版式，压缩用 q80 | 打印是主要学习动作，清晰度比多省几百 MB 重要 | 压缩后约 1.7 GB |
| D8 | **鼓励必须基于事实**：数据 + 具体动作，不空泛表扬 | 空泛鼓励会失效；具体进步才可持续 | 文案用本地模板 |
| D9 | **零命名拍照即录**：按图像内容识别册别/题号，不要求文件名 | 改名是额外摩擦，决定错题本能否坚持；旧照片才用文件名 | 需要页眉指纹表与真图调参；失败时多点一下 |
| D10 | **零家务**：用户只拍、做、对答案 | 决定坚持的是摩擦，不是功能数量 | 少一些手动控制，用高级筛选兜底 |
| D11 | **有效优先**：主动回忆 + 间隔 + 交错，不做被动看答案 | 看答案 ≠ 会做，间隔与交错才记得牢 | 复习会稍难，但更接近考试 |

补充说明：

- 手机拍照用系统相机 + `<input capture>`，**不做实时取景**（非 HTTPS 的 getUserMedia 受限）。
- 局域网 HTTP 即可，单用户无鉴权；数据不出本机。
- 不做 AI 生成解析——只用书上原解析，避免幻觉。

## 6. 信息架构

```
只读目录（可随索引重建）
├─ book registry (12 行): id / short / family / role / pdf / pages
├─ question catalog (from lookup.json): qid → 族 / 册 / 题页 / 答案页 / 章 / 套 / 年 / 场次
├─ marker cache: (book, page) → [{qid | n, section, y0, y1}]
└─ chapter catalog: 章号 → 章名

用户数据（SQLite 单文件 + 附件目录）
├─ capture(photo, detected_book, detected_qids, confidence, status)  # 拍照→识别→自动入库/待确认
├─ session(context, started_at, duration, note)  # 一次练习/一套卷；「时间不够」记这里
├─ attempt(qid, session_id, ts, result, source, mode)  # source: manual/photo/import
├─ attempt_tags(attempt_id, layer, tag)
├─ note / attachment(original_path, thumb_path, sha256, kind)
├─ mastery(qid, state, review_count, last_reviewed_at, next_due_at, consecutive_correct, lapse_count)
└─ settings(current_context, favorites, exam_date, weekly_target)
```

`lookup.json` 仍是唯一的题目目录来源，不在 SQLite 里复制题目表。

## 7. 技术形态

- 后端：Python 3.13 + FastAPI + SQLite + PyMuPDF + RapidOCR（全部是现有依赖）。
- 前端：移动优先单页 Web，本地静态文件；手机「添加到主屏幕」。
- 页面图：后端按需返回 JPEG（宽 1376–2200 px），前端只用 `<img>`，不引入 PDF.js。
- 附件：兼容 JPEG/HEIC；EXIF 转正 → 生成长边 1600 px 缩略图；原图按 SHA-256 去重，保留不覆盖。
- 拍照入库：上传后后台跑 OCR（页眉册别 + 印刷题号），结果带置信度；低置信进入待确认队列。
- 相机界面：两条轻量引导（上缘带页眉、题号不要被手挡）；自动透视校正/裁边，不要求拍正。
- 复习交互：手机单拇指底部两大按钮；PC 空格显示答案、1/2 评分、自动下一题。
- 打印：PyMuPDF 以 300 dpi 渲染裁切 → 轻微锐化 → A4 排版；参数在 M0 样张上定。
- 延迟预算：确认题号 → 两图 < 1.5 s；整页题号识别 < 3 s。
- 运行位置：PC 起服务，手机连同一 Wi-Fi 访问 `http://<PC-IP>:PORT`。

### M0 数据底座（不是产品代码）

- 压缩 PDF 工作副本（附录 A）；书目登记表；真题/模拟标记表；
  12 本前置目录页 OCR → 章节名表；100 题裁切抽检；三族 A4 打印样张。
- 验收：三族各抽 30 题，题干/解析裁切正确；压缩页肉眼可读；
  三族各打一张 A4 打印样张（含公式、图、手写留白）经 _ming 确认；页码转换零错位。

### M1 查题闭环

- 拍照即录、册别识别、上下文、手输、拍整页、题干/解析展示、缩放。
- 验收：用 `拍照错题/` 的 18 张真图，**完全不使用文件名**：
  正确题号进入候选 ≥ 95%；唯一高置信自动入库的准确率 ≥ 98%（宁可多问一次，不可记错）；
  单题照片无需手输的完成率 ≥ 85%；多题照片一次点选完成；失败可手输。
  确认后 p95 < 1.5 s；100 题裁切零肉眼错误。

### M2 错题本 + 批量录入

- 批量勾错、标签、笔记、照片、列表/过滤、备份、旧照片一次性导入。
- 验收：25 题模拟卷 ≤ 3 分钟录完；18 张旧照片导入为 **19 条**错题
  （`4-12 4-13错.jpg` 生成 2 条），重复导入不增加记录；200 条记录过滤/重开正常；备份可恢复。

### M3 复习与导出

- 今日复习（零决策）、单题两按钮、自动间隔、Z 族答案遮罩、掌握/顽固状态、
  一键打印卷、练习结束总结与鼓励。
- 验收：一键进入今日复习；单题操作 ≤ 2 次点击（不含思考）；全程不手动填日期；
  每日队列不超过 20 题；一次 20 题复习不泄露答案；连续 2 次做对才标掌握；
  三族各出一份 A4 打印卷由 _ming 实打确认；每次练习结束都有数据 + 下一步 + 鼓励。

### M4 自动建议（可选）

- 错题答案页按需 OCR；规范条文/关键词 → 错因候选。
- 验收：候选主观可用，不阻塞主流程。

## 9. 明确不做（v1）

## 10. 风险与应对

| 风险 | 应对 |
|---|---|
| 翻拍质量差，题号/册别识别失败 | 候选点选 + 键盘兜底；低置信不自动入库 |
| 自动入库记错题号 | 只在唯一高置信时自动入库，5 秒可撤销；否则点选 |
| 裁切切掉后续页/图 | 页尾「下一页 / 整页」；M0 抽检 |
| Z 族自包含答案在复习时泄露 | 按 【答案】 行遮罩；检测失败则退化为整页手动 |
| 只翻答案的「假复习」 | 解析默认不展开；先自评再做；连续 2 次做对才算掌握 |
| 复习队列积压变负担 | 每日上限 20 题；按到期+顽固+章覆盖排序；状态差给今日三题 |
| 压缩损伤可读性 | A/B 样张先行；原件保留到抽检通过 |
| 范围膨胀 | 以 M1 的「2 次点击、2 秒」为唯一硬指标 |

## 附录 A：PDF 压缩方案（已授权，M0 执行）

**现状**：12 本 5,120 页 4.9 GB。每页恰好一张整页 FlateDecode（无损）图；
RGB 但实际近灰度（通道差 0.02–0.05）；无书签、无 TOC、无元数据；
模拟题集为 4402×6216（约 576 dpi 存档扫描），其余 11 本为 1376×1943（约 192 dpi）。

**方案（按「阅读 + 错题打印」复核后的参数）**：

| 对象 | 页数 | 处理 | 体积 |
|---|---|---|---|
| 其余 11 本 | 4,544 | 保持原生 1376 px，转灰度 JPEG q80 | 2.55 GB → 约 1.35 GB |
| 模拟题集 | 576 | 降到 2200 px（约 290 dpi），灰度 JPEG q80 | 2.36 GB → 约 360 MB |
| 合计 | 5,120 | 页数、页面尺寸不变 | 约 1.7 GB（省约 65%） |

**证据**：`.probe/compress/16_2000px.jpg`（模拟答案页，q72）、`19_1376px.jpg`（案例答案页，q72）；
q72 下公式、上下标、中文已清晰，正式采用更高的 q80。两页均为「最密排」的答案解析页。

**打印约束**：11 本保持原生 192 dpi，不降采样；模拟题集保留 2200 px 以留打印余量。
打印卷按原尺寸或最多 125% 排版，不把半页宽的题目强行放大到整页宽。

**安全流程**：写新文件 → 校验页数/页面尺寸 → 随机抽检 → 三族 A4 打印样张 →
确认可读后才删原件（已授权）。绝不覆盖原文件；处理期间临时多占约 1.7 GB（D 盘可用 14 GB）。

**备选**：全部降到 150 dpi 可进 1 GB 内，但会牺牲打印裕量，不采用。

**耗时**：约 30–45 分钟（单进程逐页处理）。

## 附录 B：错题打印规格（质量优先）

**目标**：像原书一样清楚，并且能直接在纸上写解题过程；不是把截图硬拉满 A4。

**分辨率与缩放**

- 11 本章-题/真题原生 192 dpi；模拟题集压缩后约 290 dpi。
- 裁切按原始物理尺寸放置，**最大放大 125%**，有效分辨率不低于约 150 dpi。
- 半页宽的案例题不拉满整页宽；短题用 2-up（一张 A4 两题），长题一页一题 + 留白。
- 打印时选「实际大小 / 100%」，关闭「适应页面」的二次缩放。

**版面**

- 页眉：题号、书名简称、章名、错因标签、日期。
- 题干区：题干与图完整；下方留 **40–55% 空白**供手写（案例题默认 55%，知识题默认 40%）。
- 页脚：来源页码、第 x/y 页。
- 细线分隔，不用重边框/深色底；黑白激光友好。

**答案**

- 题面卷与答案卷分开生成，默认答案不跟题同页。
- 答案卷两种：**速查页**（只列答案字母）+ **详解页**（完整解析裁图）。
- Z 族从【答案】行拆开，保证题面无答案。

**印刷建议**

- A4、80–100 g 纸（要写字建议 100 g）、黑白激光、单面；需要时双面。
- 先打 3 张样张（C / Z / 模拟），检查 8 pt 小字、上下标、图、裁切边缘；确认后再批量。

**技术实现**

- PyMuPDF 以 300 dpi 渲染裁切 → 轻度锐化（半径约 1.2，强度 80%，阈值 3）；
- 固定版式模板，字体嵌入；参数在 M0 样张上定稿；
- 打印 PDF 单独缓存，不重复生成。

**验收**

- 三族各一份实打样卷，_ming 在正常阅读与书写距离都清楚；不丢图、不切断行；空白够写。
