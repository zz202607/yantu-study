# 岩土学习驾驶舱 · 项目总结

**一句话目标：** 把 11 本扫描题库变成「拍题号 → 秒出解析 → 自动归类错因 → 按数据复习」的本地学习系统，服务 2027 年注册岩土专业考试。

**当前版本 / 日期：** M11 学习驾驶舱 + 计划控制 + 应用内基线记分 + 四象限复盘 + 限时拆解/认题卡 + 2024 整卷复测 + 规范索引 + 规范伴读 + **题目→条文级推荐** + 打印中心 + 周报/月报 · 2026-11-03

---

## 1. 现在能做什么（用户视角）

- **首页驾驶舱**：考试倒计时（默认 2027-11-01，可改）、阶段、周目标、连续天数、错题/掌握/正确率、下一里程碑。
- **拍题**：手机拍整页 → 题号候选 → 题面/解析裁图；可多选、批量记错；裁图缓存后 <0.2 s。
- **错题本**：一题一行；4 类错因、备注、手写照片；按册/篇/时间/掌握/错因过滤；备份/恢复。
- **零决策复习**：今日队列（到期 → 新错 → 顽固，硬上限 20）；自动排期；可续做/撤销；Z 族答案遮罩。
  - **案例题**：看答案后按过程点选「过程对·结果对 / 过程对·结果错 / 过程错 / 没思路」，
    可拍手写过程照片随评分保存；不按选项字母判分。
  - **知识题**：仍是「没做对 / 做对了」两按钮；答案键判分另走客观题模块。
- **数据统计**：九大类（+土力学）错题与正确率、按节细分、错因分布、14 天活动、题库覆盖、2025 基线总分/正确率。
- **计划控制**：五阶段（基线/基础/强化/套卷/冲刺）、每周 10–12 小时、阶段目标、
  练习记录（作答/做对/放弃/超时/用时）、计划 vs 实际、落后/弱项/超时纠偏规则。
- **应用内基线记分**：计划页直接记 2025 上午/下午两半；四个数 + 可选逐题
  「对/错/弃 + 超时」；录满 25 题自动算并锁定；每半 50 分、两半合计 100 / 通过线 60；
  九大类分项、错题一键入本、答案纸照片；不再需要电脑 CLI。
- **四象限复盘 + 弃题分流**：会且快 / 会但慢 / 做错 / 放弃，各自对应
  维持 / 限时 / 补原型 / 分流；放弃题标「没时间 / 不会」，没时间留在限时重做清单。
- **训练：限时拆解 + 认题卡**（计划页；首页行动卡直达）：
  - 限时拆解 5–10 题 × 8 分钟硬上限；每题写首步卡；结果做对/做错/超时/放弃，
    放弃必须已写首步；完成后自动进周计划题量。
  - 认题卡 5–10 题 × 30 秒；只认原型与主规范，提交即显示对错；不计题量，自动换题。
- **整卷复测 · 2024**（计划页）：2024 上午/下午卷 PDF（题面在前、答案封存、封面带结果格）；
  两半各 180 分钟；只在 App 记四个数（作答/做对/放弃/超时），合计 100 / 通过线 60；
  记录进周计划，但不会改动 2025 基线分项。
- **规范联动**：九大类 → 核心/配套规范 → 本机 PDF 一键打开；**规范章节索引**
  （核心 7 本，选规范 → 章节树 → 页图；条文号 `5.2.4` 定位到 5.2 节）；
  规范 OCR 引用直接带链接；工程地质手册全文检索 + 页图查看。
- **规范伴读（M10）**：9 本核心规范、67 站；按案例权重排路线（抗震 → 特殊土 →
  地基处理 → 浅基础 → 基坑 → 边坡 → 勘察 → 深基础）。每站 6–18 分钟，
  看**标注版原页**（红线/旁注保留），配「为什么考 / 先看什么 / 最容易错 /
  30 秒自检 / 条文 chips / 一组同类题」；已读/需回看进度落库，首页有
  「继续下一站」卡片，支持深链直达。标注版页索引由页脚 OCR + 锚点插值建成，
  校不上时标「估」并可回退干净版。
- **题目 → 条文级推荐（M11）**：错题详情点「规范定位」，直接列出这题对应的
  规范、条文和页码。来源分三层并明确标注：「解析依据」（M4 已读解析里的精确引用）、
  「原型重点」（题目所属案例原型 → 伴读站条文）、「章节匹配」（章节名/题干关键词 →
  考点词表）；点击任一条直达本机规范页图，底部保留「按大类看规范」。
  解析引用没有页码时明确标「未收录」，不猜；没有伴读路线的规范会如实显示缺推荐。
- **周报/月报**：数据页按自然周/月生成一页，包含练习四个数、计划达成、复习日志、
  新增错题/掌握/顽固、对比上期的增减、九大类分项、每日节奏、2025 基线、
  三条下一步和一条带数据依据的鼓励；可保存为 `data/reports/<key>.md` + `.json`，
  在 App 内查看快照/下载/删除。空周会明确写「没有记录」，不编数据。
- **打印**：A4 题面/答案分页、手写区、Z 族拆分、封面任务单、每题结果回填格、
  本周任务卷（按未完成原型选 30 题）、JPEG 压缩；2025 基线上午/下午卷可直接下载。
- **照片存储**：新照片 2400px q85、缩略图 480px；按 sha 去重；设置页可清理旧过程照片
  （每题保留最近 2 张，标记原图不删，清理前自动备份）。
- **手机形态**：底部 5 栏导航、移动优先布局、PWA manifest/图标；浏览器「添加到主屏幕」可当 App 打开。

## 3. 关键决策（带理由）

1. **索引只读，用户数据独立**（D5）：重建题库不影响错题本；`data/` 可整体 zip。
2. **图像优先，OCR 只做定位**：扫描件无可靠文字层；题号/规范号用 OCR，题干公式插图保留原图。
3. **题号必须校验**：候选只在唯一高置信 `start` 时自动打开；残读用当前册题号集合唯一解，不模糊猜。
4. **零决策复习**：排期、题量、顺序由系统决定；用户只做「做对/没做对」。
5. **重活按需 + 缓存**：答案页 OCR、手册全文索引、页图渲染都按需生成，失败不阻塞详情页。
6. **统计口径固定**：正确率 = 复习日志中 correct / (correct + wrong)，窗口默认 30 天；不从单次 `last_result` 推断。
7. **知识分类以案例篇为准**：C1–C10 与考试九大类一一对应（C1 土力学权重 0）；A2025 真题按标签映射；K/Z/非 2025 真题保持「未归类」。
8. **规范匹配先编号后书名**：GB/JGJ 等编号规范化后精确匹配；书名模糊匹配只在唯一时采用，避免打开错误规范。
9. **手册页码用 PDF 页（书签口径）**：与 standards-map 一致；界面明确写「PDF 第 N / 1426 页」，避免与印刷页码混淆。
10. **PWA 而非原生 APK**：同 Wi-Fi 本地服务 + 手机浏览器即可用；局域网 HTTP 下系统不弹自动安装，提供「添加到主屏幕」说明。
11. **案例与知识题判分分家**：案例是主观题，只能按过程人工选状态；知识题是客观题，
    用 `app/objective.py` 做单选/多选精确匹配。资料书里的 A/B/C/D 选项不是考试判分依据。
12. **计划按「四个数」控制，不按感觉**：错题本只知道错题，不知道做了多少题；
    所以计划模块单独记录 `practice_sessions`（作答/做对/放弃/超时/用时），
    否则无法判断落后、平均时间和阶段进度。
13. **规范索引优先用目录，不 OCR 全文**：核心 7 本目录级索引已足够 30 秒定位；
    正文检索只用于 21 本有文字层的标准，扫描件不假装能全文搜。
14. **纸面做题，手机只做相机/记录器**：打印任务卷 + 封面回填格 + 每题状态格，
    避免在手机上验算；A4 一页一题给案例题留足手写区。
15. **基线先入库，CLI 只回填**：`baseline_runs` 是主记录，首页/统计/计划先读数据库；
    保存半卷同时 upsert 同一条练习台账（`baseline_half` 唯一索引），改分不重复计数；
    只有数据库为空时才读旧 markdown。
16. **周期报告用自然周/月，不用滚动窗口**：周报固定周一–周日（ISO 周号），月报固定自然月；
    目标按「每日折算」跨阶段摊平（基线周 0 题、基础期 20 题/周，11 月合 63 题），
    这样阶段切换不会把月目标算错。进行中的周期只按已过天数算「截至今日目标」，
    对比上期取同期切片；未来周期标「未开始」，不提前判落后。
17. **保存报告 = 冻结快照，不改历史**：保存时写 `.md` + `.json`，同一期重存覆盖；
    之后修改错题/练习不会改已保存的页；要看最新数字就重新生成。
18. **空周期必须诚实**：没有练习/复习就写「没有记录」，下一步给最短行动；
    不拿上期数字冒充本期，也不用「0 题 · 0%」制造虚假进展。
19. **必拿顺序以个人基线为准**：通用蓝图只给初始排序；2025 基线显示必拿四类
    （浅基础/特殊土/地基处理/地震）作答正确率只有 42%，其余五类 73%——
    先修个人弱项，不照搬「特殊土/地震优先」。分类统计必须能改变下一步。
20. **四象限要配不同动作，不能只计数**：会且快=维持、会但慢=限时、做错=补原型、
    放弃=先分流「没时间/不会」；「没时间」不进错题本，否则无时限复习会把它提前
    判成掌握，掩盖速度问题。
21. **训练真值用题库结构，不靠模型猜**：认题卡的原型答案直接来自
    `PROTOTYPE_RANGES` 题号区间；B4/B5 重叠时两个都接受，展示更具体的 B5；
    主规范只在课程核心列表唯一时出题，冻土/滑坡/泥石流只判原型，不编造规范号。
22. **只有同一种能力才进同一本台账**：限时拆解是做题，完成后写
    `practice_sessions`；30 秒认题卡是识别训练，只进 `drill_sessions`。
    否则周计划会被「秒选原型」灌水，看起来题量很高但计算能力没变。
23. **硬上限用绝对 deadline，不用每次渲染重置**：看答案、重渲染、切题都不
    重置计时；到 0 后「做对/做错」禁用，只能记超时/放弃。放弃还必须已写首步，
    把「不会就跳过」改成「不会也留下可得分的第一步」。
24. **复测换未做过的卷，且只记四个数**：2025 是基线烧卷，12 月中用 2024；
    2024 没有逐题类别标签，就不编分类，只用四个数判断是否过线。
    整卷记录与练习台账的键必须带年份（`2024-A`），否则第二年复测会覆盖基线台账。
25. **打印题号从索引生成，不手抄**：过滤幻影题号、要求连续且题量正确；
    封面直接印结果回填格，做完照封面录 App，避免翻 32 页找题号。
26. **规范伴读按「站」而不是按「本」**：每站 6–18 分钟、对应一个案例原型，
    有明确的「看完/需回看」状态；整本通读投入产出低，短路线才可能每天执行。
    页面用标注版原页而不是二次总结，解释只做导航，不重写条文。
27. **标注版页码不靠固定偏移**：2-up 扫描件的目录页与正文页号重复，且前置页
    数量不一；必须先用页脚 OCR 找正文起点，再用单调锚点插值，最后按站校验。
    OCR 校不上时保留插值并显式标「估」，不假装精确。
28. **条文推荐分层，不合并成一个模糊分数**：解析 OCR 的精确引用最强，其次是
    题目原型对应的伴读站，最后才是章节关键词。每行必须带来源和页码；解析引用
    解析不到页码就报「未收录」。关键词只在本大类内匹配，跨类只留滑坡/检测这类
    明确白名单——宁可少推荐，也不把用户带到错误规范。

## 4. 有效做法（可复用）

- 先做真实样本基准（18 张照片、100 题裁切、29 题答案 OCR），再优化。
- 每个重活都有磁盘缓存和降级路径。
- 每个数字都能追溯：统计 → 题号 → 解析 → 规范条文/手册页。
- 首页把「接下来做什么」放在第一屏；鼓励语由真实日志生成。
- **周期报告先定边界再算数**：周/月的起止、上期、目标先算清楚，再做展示；
  对比上期只对比可比的字段（练习/复习/正确率），不硬凑总分。
- **报告同时产出两种形态**：页面用结构化 JSON 渲染，保存时生成 Markdown 一页；
  屏幕好看和可归档不冲突。
- **基线按四象限复盘**：会且快 / 会但慢 / 不会 / 放弃，分别对应维持 / 限时 /
  补原型 / 认题；只看正确率会把「13 道超时做对」隐藏掉，也会把「6 道又快又对」看不到。
- **训练入口放在计划页，结果写回同一个周计划**：练完自动计入题量，用户不用
  再手填一次四个数；「再来一组」沿用上次模式/来源/题量，减少决策。
- **认题卡用轮换而不是随机**：同一来源下跳过已用 qid，下一组自然换题；
  随机抽题会重复，轮换能保证覆盖新的原型/题目。
- **复测与基线共用「整卷记录」，但按键带年份分开**：复测复用同一套
  50 分/半、100 分总分的规则，只多一个年份维度；这样不用维护第二套评分逻辑，
  也不会让 2024 覆盖 2025 的台账。
- **打印件自带录入表**：封面 25 题逐题结果格，做完照封面在 App 里点四个数，
  纸面到数字的路径最短。
- 打印样张实际打印验收，不只屏幕预览。
- 每个模块写 journal；每个里程碑写本 SUMMARY；跨项目经验回流根目录 `LESSONS.md`。

## 5. 失败 / 限制（不要重复）

- **单页识别册别不可行**：同系列册页眉高度重合，指纹仅 23–38%；最终靠用户选册 + 记忆。
- **页底墨迹判断续页会被水印骗**：改为看下一页首题号位置。
- **激进折痕清洗会抹掉 `1`、`+`、`【】`**：只保留保守版。
- **`M2-5` 答案页**：p34 的「5.」OCR 未检出，仍是已知缺口。
- **K/Z 与非 2025 真题没有九大类映射**：统计里单独列为未归类，不强行归类。
- **旧基线脚本曾把案例当选择题**：用华S 资料的 A/B/C/D 选项算分，与「只有答案无过程 0 分」
  矛盾；已改为四个数 + 过程状态，教训见 `docs/journal/2026-11-02-case-subjective-fix.md`。
- **基线只保留最近一次半卷**：没有多次基线历史，重考就改同一条；
  逐题只有结果/超时/过程状态，没有逐题照片与逐题备注（答案纸照片是半卷级）。
- **部分逐题不会推断未录题**：分项统计只含已录题，界面用「逐题 n/25」标明覆盖率；
  逐题与四个数冲突时服务端拒绝保存。
- **案例仍不按选项字母判分**：边界见 `docs/objective-scoring.md`。
- **考试日期是估算**：默认 2027-11-01，官方日期出来后要在设置里改。
- **规范库在 E 盘**：换机器/盘符需设 `YANTU_STANDARDS_DIR`；手册路径可用 `YANTU_HANDBOOK`。
- **LAN HTTP 不能自动安装 PWA**：需要浏览器菜单手动添加；要大图标/独立窗口可后续做 HTTPS 或原生壳。
- **报告只保留每期最后一版**：同一周/月重存覆盖，没有版本历史；需要留档就另存/导出。
- **报告取练习台账最多 200 条/期**：个人节奏够用；一天几十条练习记录才会截断。
- **手工改 `.md` 不会回写 `.json`**：页面和后续对比以 `.json` 为准，改文字不影响数字。
- **报告里的「现状」是生成时点**：错题本总数/掌握数是当前值，不是历史时点；历史只冻结已保存的 Markdown。
- **弃题分流只覆盖逐题录入的 `skipped`**：只记四个数、没有逐题的半卷无法分流；
  界面会明确显示逐题覆盖率。
- **超时题入本仍走无时限复习**：`correct+overtime` 可以入错题本（单独备注），但复习
  队列本身不计时；速度训练走「限时拆解」，入本只解决“再见一次”。
- **限时拆解中途恢复会重新计时**：没有逐秒落库，恢复的那一题从 8 分钟重新开始，
  不假装知道上次已用多久；如果以后需要精确，要存已用秒数。
- **认题卡不能只练上一组错的原型**：目前靠「再来一组」在弱项原型间轮换；
  错题→原型聚焦的闭环还没做。
- **整卷复测只支持 2018–2024、且只有四个数**：2024 卷没有逐题类别标签，
  不做分项、逐题状态、答案纸照片；2015 在 lookup 中缺号，无法打印。
- **复测分数与基线分项不互通**：2024 的 62 分只说明是否过线，不能回答
  「哪一类弱」；要分项得等有标签的卷或人工补标签。
- **复测记录复用 `baseline_runs`**：`items_done=0` 表示这是只记四个数的卷；
  界面不要把它误显示成「逐题 0/25 的基线」。
