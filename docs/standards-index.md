# 规范章节索引

状态：M6 · 2026-11-02

## 目标

开卷考试的瓶颈是「找不到」：知道考哪本规范，但 30 秒内翻不到章节。
索引把「规范 → 章/节 → 印刷页 → PDF 页」一次建好，App 里点章节直接看页图。

## 数据来源（按优先级）

1. **文字层目录**：PDF 自带文字，直接解析「目 次」/「目录」，印刷页准确。
2. **OCR 目录**：扫描件 OCR 前置目录页；110 dpi 保留页码，150 dpi 保留标题，两者合并。
3. **PDF 书签**：没有可用目录时退回书签，只能到粗章节。

页码偏移 = PDF 页 − 印刷页；优先用「目录后的第一处章节标题」反推，
失败时用页脚独立页码。偏移和估算项都会在索引里标明。

## 覆盖

当前 50 本标准中 37 本有目录级索引（核心 7 本全部覆盖）：

| 标准 | 来源 | 说明 |
|---|---|---|
| GB 50007-2011 | OCR 目录 | 5.2 承载力等关键节可用 |
| GB 50021-2001 | OCR 目录 | 73 条 |
| JGJ 79-2012 | OCR 目录 | 43 条 |
| GB 50330-2013 | OCR 目录 | 46 条 |
| JGJ 94-2008 | 文字目录 | 53 条 |
| GB 50011-2010 | 文字目录 | 80 条 |
| JGJ 120-2012 | PDF 书签 | 18 条 |

剩余 13 本扫描件可用 `--merge` 增量补 OCR；没有目录的标准仍可从「规范库」直接打开 PDF。

## 重建

```bash
PYTHONIOENCODING=utf-8 py -3 tools/build_standards_index.py
PYTHONIOENCODING=utf-8 py -3 tools/build_standards_index.py --only "GB 50007,JGJ 79" --merge
PYTHONIOENCODING=utf-8 py -3 tools/build_standards_index.py --no-ocr   # 快速：只用文字/书签
```

- 输出：`index/standards_index.json`（章节标题与页码，不含正文）
- 正文缓存：`.cache/standards_text/<code>.json`（仅 21 本有文字层的标准）
- 页图缓存：`.cache/standards_pages/`（可随时删）

## 使用

- 「数据 → 规范」顶部：选规范 → 章节树；点章节打开 App 内页图。
- 条文号输入 `5.2.4` → 解析到 5.2 节 → 打开对应页。
- 错题详情的规范引用：有索引时点击直接打开章节页，否则打开原 PDF。
- 页图下方「原 PDF」可打开完整规范；「放大」看小字。

## 已知限制

- 扫描件没有正文文字层，只能到目录级；条文号精确到节，不保证到条。
- OCR 目录有噪声：页码跳变会被夹到相邻节并标记「估」。
- 索引不替代原图：引用和数字一律看规范原页。
