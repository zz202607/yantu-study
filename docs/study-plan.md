# 备考策略：把通过概率做上去

状态：草案（未写代码） · 2026-10-31 · 目标考试：2027 年 11 月
依据：`docs/exam-blueprint.md`（考题分布）+ 华S 资料前言 + 案例真题册评分标准

## 1. 先算清楚通过线

| 项目 | 数值 | 来源 |
|---|---|---|
| 案例 | 上下午各 3 小时，各 25 题，每题 2 分，共 100 分 | 真题册前言 |
| 案例合格 | 机读 ≥ 60 → 人工复评 ≥ 60 | 同上 |
| 即：做对 | **30 题**（允许错和放弃合计 20 题） | 推算 |
| 平均时间 | **7.2 分钟/题**（180 min ÷ 25） | 推算 |
| 真题重现 | **历年考点占 50%~60%，相似题重现率高** | 真题册前言原话 |
| 知识 | 上下午各 40 单选 + 30 多选，200 分，机读 ≥ 120 | 知识习题册前言 |
| 知识构成 | 七本核心规范 + 手册 + 土力学 + 法规 ≈ 140 分（70%） | 同上 |
| 评分 | **仅有答案无过程一律 0 分**；引用条文号与答案一致才得分 | 真题册评分标准 |

**两个结论：**

1. 案例不是「全会」的考试，是「**30 题不失手**」的考试。60% 的题目你本来就可以不做。
2. 知识是筛子不是门槛：七本核心规范 + 真题，稳定 150 分即可收手。**时间应 8:2 甚至 9:1 投向案例。**

## 2. 把 50 题拆成三档

按 `exam-blueprint.md` 的题量与「考题特点/答题策略」原话：

| 档位 | 类别 | 题量 | 目标正确率 | 期望做对 |
|---|---|---:|---:|---:|
| **必拿** | 特殊土 7 + 地震 4 + 地基处理 6 + 浅基础 8 | 25 | 95% | 23.8 |
| **争取** | 勘察 8 + 深基础 5 + 检测 2 + 边坡常规 3 | 18 | 70% | 12.6 |
| **视情况** | 边坡偏难 3 + 基坑 4 | 7 | 会就做，不会就跳 | — |
| 合计 | | 50 | | **约 36 题 ≈ 73 分** |

边坡不是整篇放弃：蓝本原话是「部分常规题易拿分，大部分常规考点可达到闭卷作答程度」。
土压力、圆弧滑动、重力式挡墙、锚杆这四类要按「争取」对待（见 `prototypes.md` C 部分）。

书上的建议答题顺序：**地震 → 特殊土 → 地基处理 → 浅基础 → 基坑 → 边坡 → 勘察 → 深基础**，检测视情况。
注意这个顺序和题量权重一致：先吃最稳的 25 题，把 60 分的基本盘锁死，再谈别的。

## 3. 四个杠杆（按回报排序）

1. **历年真题**：占考点的 50%~60%，是唯一有实证的提分材料。
   做法不是「按年份刷一遍」，而是**先按类别拆开练**（把 2012–2025 全部特殊土题放一起做），
   再**按套卷限时**回到考场节奏。两轮目的不同：第一轮学，第二轮练时间。
2. **题型原型清单**：50 题背后是有限的原型（如「液化指数计算」「复合地基置换率」「软弱下卧层验算」）。
   每个原型做成一张卡：条件 → 公式 → 3 个坑 → 规范条文号。目标 25–30 个原型闭卷可写。
   这是把「见过」变成「会做」的唯一路径。
3. **规范定位**：开卷考试的真正瓶颈不是不会，是找不到。
   七本核心规范 + 工程地质手册做书签/目录索引，练 **30 秒定位**：看题 → 哪本 → 哪条/哪表。
   手册主要出在不良地质和特殊土（第五、六篇，p532–786），页码要熟。
4. **土力学内功**：案例的计算骨架是土力学（三相、有效应力、固结、强度、土压力、边坡）。
   教材 = 李广信《土力学》第 3 版，9 章。它是「慢变量」，前期投入，全年受益。

## 5. 软件的三项职责（不刷题，只做加速器）

- **按类别抽题出限时卷**：不是按年份，是按「必拿/争取」档位组卷，打印成 A4 手写卷
  （评分标准要求写过程，所以必须纸上练）。
- **四类错因 → 四种动作**：`不会` 回教材章节 / `算错` 限时重算 / `规范错` 30 秒定位 / `审题错` 审题清单。
- **依据索引**：把错题接回规范条文，直接服务「定位」这个考试核心动作。

## 6. 第一周就能做（不需要系统）

1. **测基线**：限时 3 小时做一套完整案例真题，只记录四个数——作答题数、做对数、放弃数、超时题数。
   这一张表决定后面所有排期。
2. 把 25 个原型列出来（可从真题册目录 + 习题集点评反推）。
3. 七本核心规范贴标签/书签。
