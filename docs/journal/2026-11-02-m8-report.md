# M8 周报/月报：把统计与下一步冻结成一页（2026-11-02）

北极星：交完 2025 基线后，每周日打开 App 就能看到「这周做了什么、弱在哪、下一步做什么」，
并且能把这一页存下来，下周/下月直接对比。

## 决定

- **周期用自然周（周一–周日，ISO 周号）和自然月，不用滚动 30 天。**
  周报要能固定在同一天复盘；ISO 周号可用 `week-2026-W45` 做稳定文件名。
  月报固定自然月，避免「每月 15 日」这类漂移边界。
- **报告是投影，不新增事实表。** 练习四个数来自 `practice_sessions`，
  复习来自 `review_log`，新增错题来自 `attempts.created_at`，基线来自
  `baseline_runs`，计划来自 `plan.json` + 阶段表。没有新表、没有新采集。
- **目标按天折算，跨阶段不重算错。** 月报不是「周目标 × 4」：11 月前 8 天是基线周
  （0 题），后 22 天是基础期（20 题/周），合计 `22 × 20 / 7 ≈ 63`。
  实现上逐日累加 `weekly_target / 7`，阶段边界自动正确。
- **只对比可比的字段。** 上期只对比练习题数、复习次数、正确率（百分点）；
  不把「总分」硬凑出来。上一期没有数据时，正确率差值为 `null`，界面不显示。
- **进行中的周期按已过天数折算目标。** 11 月 2 日打开月报，截至今日目标仍是 0
  （前 8 天是基线周），不能拿全月 63 题说「落后 21」；周报同理。
  对比上期也取「上期同期」切片（本周 3 天 vs 上周前 3 天），而不是整周对 3 天。
  未来周期标「未开始」，不产生「没有练习」的指责式行动。
- **保存 = 冻结。** 保存写 `data/reports/<key>.md`（给人看/归档）和 `.json`
  （给页面重新渲染/后续对比）。同一期再次保存覆盖同一对文件；
  保存后修改错题/练习不会改已保存的页。
- **空周期必须诚实。** 没有练习也没有复习时，鼓励语写「还没有记录」，
  下一步给最短行动；不拿错题本存量冒充本期活动。
- **下一步最多 3 条，全部路由到现有页面。** 基线未交 → 基线页；到期复习 → 复习；
  弱项 → 规范地图；落后 → 计划；新错未复习 → 错题本。没有行动时给「节奏正常」。
- **报告进备份。** `reports/` 与 `settings.json`、`plan.json` 一起进 zip；
  恢复时带回，避免换机丢失复盘记录。
- **鼓励带证据。** 复用首页规则：每条鼓励都带「练习 X 题、做对 Y；复习 Z 次、
  做对 W；新增错题 N」的依据。

## 数据与接口

- `report.period_info(period, anchor)`：返回 start/end/ISO key/label/上一期/下一期锚点/是否本期。
- `report.build(store, data_dir, settings, ...)`：纯读取，返回页面所需 JSON + Markdown。
- `report.save/list_saved/load_saved/report_file/delete_saved`：
  - `save` 原子写 `.md` + `.json`，同 key 覆盖；
  - 文件名只接受 `week-YYYY-Www` / `month-YYYY-MM`，防止路径穿越。
- API：
  - `GET /api/report?period=week|month&anchor=YYYY-MM-DD`
  - `POST /api/report/save`（body: period/anchor）→ 报告 + 已保存列表
  - `GET /api/reports`、`GET /api/reports/{key}`、`GET /api/reports/{key}/file`
  - `DELETE /api/reports/{key}`
- 备份：zip 增加 `reports/*.md|json` 与 manifest 的 `reports` 计数；恢复时整体带回。

## 页面

- 数据页新增「周报」标签，内部再切「周报 / 月报」。
- 顶部深色卡：周期标题/范围/阶段/进度；基线周显示「已交 n/2 半」而不是题量。
- 上一期 / 本期 / 下一期；「保存本页」。
- 证据型一句话 + 8 格关键数字（练习、正确率、复习、复习正确率、新增错题、
  新掌握、小时、计划达成）+ 对比上期。
- 分项表：练习（正确率）/ 复习（正确率）/ 新增错题，行内小字显示基线正确率。
- 每日节奏柱状图；2025 基线卡；三条下一步；已保存报告列表
  （查看 Markdown 快照 / 下载 / 删除）。
- 深链：`/?tab=data&view=report`。

  - 周一起始、跨年 ISO 周、闰年 2 月、12 月→次年 1 月；
  - 只统计周期内练习；上期同期切片；跨阶段月目标（11 月 = 63）；
    进行中月份按截至今日目标判断；未来周标「未开始」；
  - 复习日志/会话/掌握转换；九大类映射；基线分项与行动；
  - 空周期诚实输出；保存覆盖、列表、读取、下载、删除、非法 key；

## 已知缺口

- 同一期只保留最后一版，没有版本历史；需要留档就下载/另存 Markdown。
- 每期最多读 200 条练习记录（个人节奏足够；一天几十条才会截断）。
- 手工改 `.md` 不会回写 `.json`；页面/后续对比以 JSON 为准。
- 「错题本共 N / 掌握 N」是生成时点的现状，不是历史时点；历史只冻结在已保存 Markdown。
- 报告不自动生成/推送：周日需要点一次「保存本页」。
