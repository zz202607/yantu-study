# 2026-10-31 · 25 个原型清单 + 规范定位地图

## 做了什么

1. 从三个案例习题集的**前置目录**（OCR，200 dpi）建立「篇 → 章 → 节 → 书页」的完整结构表。
2. 用 `index/lookup.json` 把每一节的书页换算成 PDF 页，再取该页的第一道题号，
   得到 **25 个原型 → 题号区间 → 题量 → 解析页/空白页** 的对照表。
3. 用本机 50 本规范库的文件名 + 手册书签，建「九大类 → 核心规范/配套规范 → 手册篇章页码」的定位表。

产出：
- `docs/coach/prototypes.md`
- `docs/coach/standards-map.md`

## 关键发现（影响后续所有实现）

**案例册 qid 的第一段是篇号，不是章号。** 数据：C1 有 373 题，横跨土力学 9 章；
C2 从 PDF p209（书 p191，第二篇首页）开始。十篇与考试九大类一一对应。
→ 按篇抽题不需要任何额外映射，这是运气很好的结构。

**lookup.json 有 8 条脏数据**：
- 4 个规范号误判成的伪章节（`C72-201`、`C40-23`、`C94-200`、`C79-201`），
  其中 `C94-200` 因为反复出现，挂了 8 个页码，`confirmed` 还是 true
- 4 个跨册幻影（同一题号在非归属卷上被误检）
→ 取题必须按归属卷过滤：上=1/2/3、中=4/5/6、下=7/8/9/10。不修也不影响练习，M0 再清。

## 决策

- **原型按节切，不按章切。** 章是规范单位（一个规范一章），节才是考法单位
  （预压 vs 复合地基 vs 换填）。25 个原型 = 17 必拿 + 8 争取。
- **首轮只做 300–400 道**，不是 2,491 道；每个原型 10–15 道，按计算题优先。
- 规范映射只写**能从本机资料核实**的编号，不凭记忆补标准号。
