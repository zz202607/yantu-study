# 伴读精读：翻页顺手化 + 真题足迹

2026-11-17 · UX + 数据

## 症状（_ming 实测反馈）

1. 精读模式翻页不顺手，**全屏时尤其明显**：翻页键在顶部工具栏，读书时视线在页面底部；
   手机上没有键盘和左右键，只能去够顶部两个小按钮。
2. 想在规范旁边看到**真题考察的年份和题号**，现在只能靠翻真题书自己回忆。

## 决定

### 一、翻页：把控制放到手边，而不是顶部

不重做阅读器，只在现有精读层上加四条同义通道：

- **浮动翻页条**：页面底部居中，44px 圆角按钮 + `p 37 / 350`，始终不随页面滚走；
  手机按钮放大到 52×44。
- **页面两侧边缘热区**：桌面 hover 显现，点击翻上一页/下一页；不可用时自动隐藏。
- **滚轮越界翻页**：宽度铺满时，滚轮先把当前页滚到底；在页底继续滚才翻下一页，
  顶部反向同理。触控板横向滑动（`deltaX`）直接翻页。650 ms 冷却防连翻。
- **手机左右滑** + `Space / Shift+Space`；原有 `← →`、`PgUp / PgDn`、跳页输入保留。
- 顶栏页控件在 620px 以下隐藏；保留在桌面（跳页仍更快）。

为什么不做连续滚动：标注版一页内容密度高，连续滚动会让「一站」边界消失；
当前需求是「从一页到下一页不费劲」，不是改成 PDF 阅读器的长卷。

### 二、真题足迹：只收有证据的引用

**数据来源是 OCR，不是记忆。** 新增 `tools/build_exam_refs.py`：

1. 覆盖 `lookup.json` 里有题面页和答案页的案例真题 A 族（2012–2025，共 700 道；
   2015 年考试停考，自然缺失）。
2. 先 OCR **答案解析**（解析会点名这题依据的规范），解析无引用再 OCR **题面**
   （题面常写「按《…规范》GB …」）。2025 两卷已有机器文本，直接读 `index/tags/`。
3. 用现有 `extract_citations` 抽《规范》标题、标准号、条文号；只保留能在本机
   50 本规范索引里精确解析的条目，解析不了就丢掉，**不猜**。
4. 输出 `index/exam_refs.json`：每题 → 被引用的规范 + 条文 + 证据类型
   （真题原文 / 答案解析 / 题面引用）。断点续跑，每 10 题原子落盘。

放置方式分三层，按证据精度递进：

| 位置 | 内容 | 归位依据 |
|---|---|---|
| 伴读站页「真题足迹」 | 本站精确命中 + 可展开的整本规范历年真题 | 条文号落在本站条文/节 |
| 精读右栏 | 当前站的题号 chips；本站无条文号时退回整本最近 8 题 | 同上 |
| 阅读路线行 | `真题 n` 徽标 | 同上 |

- 没有条文号的引用**只留在规范级**，绝不硬塞到某一节。
- 点击题号：桌面新开 `/?qid=…` 标签页，精读原页不丢；手机关精读、用应用内查看器。
- 区块显式写明「只收录解析或题面明确引用的真题」和索引覆盖率
  （已索引 n/700），不把「没查到」说成「没考过」。

### 三、两个实现细节

- `answer_ocr.CODE_RE` 允许标准号里有一个空格（`GB 50007-2011`），
  这样 2025 的文本（未去空格）也能在引用后读到条文号；OCR 路径本就无空格，不回归。
- 精读栏在 900px 以下隐藏，题号仍在「要点」抽屉里；不在手机上加第三列。

## 实现

- `tools/build_exam_refs.py`：OCR/文本建索引；`--limit` / `--year` / `--force` /
  `--no-question`；缓存 OCR 结果到 `.cache/exam_refs/`。
- `app/exam_refs.py`：读索引、按标准/站分组、标注证据与覆盖率；
  条文→节匹配只认精确前缀与附录。
- `app/reading.py`：`detail()` 增加 `exam`（整本）+ 每站 `exam_refs/exam_count`；
  `overview()` 增加每本规范 `exam_count` 与全局覆盖率。
- `app/static/index.html`：
  - 精读结构改为 `rr-body`（页面 + 右侧真题栏 + 浮动翻页条 + 两侧热区）；
  - 新增 `readingExamChips / readingExamBlock / renderExamRail /
    renderReadingPager / flipReadingPage / openReadingExamRef`；
  - 滚轮/触控板/触摸滑动/Space 翻页；顶栏页控件在手机上收起。

## 验证

- `pytest` **358 条全绿**（新增 9 条：索引缺失、排序与标签、条文归站、
  附录匹配、detail 注入、解析/裸标题/未知标题）。
- CDP 无头 Chrome 1440×900 + 390×844：
  - 站内「真题足迹 15 题」、2024上午6/8 带 `5.2.7`，右栏「本站真题 · 2 题」；
  - 浮动翻页条 p37→p38，滚轮越界 p38→p39，左侧热区 p39→p38；
  - 手机右栏隐藏、翻页条 220×56 可见，触摸左滑 p38→p39；
  - 桌面题号开新标签且精读不关，手机题号走应用内查看器；
  - 0 JS 异常。
- 索引构建（本机 CPU）约 8–10 s/题；首批 2025 文本即时完成，2012–2024 按年倒序
  后台补齐，随时可重跑续建。

## 边界

- 只索引**案例真题 A 族**；知识真题 K 族与模拟题尚未进索引。
- 解析先于题面：如果解析引用了 A 规范、题面只写 B 规范，当前只记 A；
  这是证据优先的取舍，后续可改为两遍都读。
- OCR 可能漏读；漏读表现为「没有记录」，不会被编造成错误记录。
- 真题书无文字层，索引是离线一次性成本；页图与索引都只在本机，不上传。
