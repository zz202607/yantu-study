# M6 计划控制 + 规范章节索引 + 纸面打印中心

日期：2026-11-02 · 状态：完成（155 条测试全绿）

## 为什么做

M5 解决了「有什么」：倒计时、统计、规范地图、手册。_ming 确认后要解决
「怎么稳步推进」和「怎么在纸上做题」：

1. 题目做不完也不需要做完；需要计划、练习记录和纠偏，而不是更多内容。
2. 开卷考试找不到条文；需要「标准 → 章节 → 页」的索引。
3. 手机不适合验算；需要把纸面做题、回填、错题录入接成一条流水线。

## 计划模块

### 数据

`data/wrongbook.db` migration v4：

- `practice_sessions(id, day, source, category, attempted, correct, abandoned,
  overtime, minutes, note, created_at)`：一次练习 = 四个数。
- `plan_progress(key, status, accuracy, note, updated_at)`：
  `prototype:A1` / `soil:1` / `standard:C3` 的手动打勾。
- `data/plan.json`：只存 `weekly_hours`（默认 11，按 10–12 h/周）。
- 备份/恢复包含 `plan.json`。

### 计算

`app/plan.py`：

- 五阶段：基线（11-02~11-08）→ 基础 → 强化 → 套卷 → 冲刺；最后一段跟随
  `settings.exam_date`。
- 周题量：20 / 32 / 38 / 55，按 `weekly_hours / 11` 缩放。
- 计划 vs 实际：周实际、阶段进度、必拿类正确率、平均分钟、复习到期。
- 纠偏规则：落后 10–20% 砍低频；连续两周落后 >20% 减新题；必拿 <85% 停新题；
  平均 >10 分钟先做限时拆解；复习积压先清复习。
- 任务生成：本周差额、未完成原型、土力学章节、核心规范、周日周报。
- 打印选题：未完成原型对应题号范围（`PROTOTYPE_RANGES`），新题优先。

### UI

- 「数据 → 计划」：阶段卡、周进度、阶段目标、本周任务、原型/章节/规范清单、
  最近练习记录、纠偏提示。
- 「记一次练习」：日期/来源/类别/作答/做对/放弃/超时/用时/备注。
- 「调整计划」：每周小时数。
- 首页新增本周计划卡，点开计划页。

## 规范章节索引

### 构建

`tools/build_standards_index.py`：

- 文字层目录优先；扫描件 OCR 前置 16 页。
- OCR 双分辨率：110 dpi 保留页码，150 dpi 保留标题，按节号合并。
- 中文/英文目录同时存在时，中文标题优先。
- 页码偏移用目录后第一处章节标题反推；OCR 页码跳变夹到相邻节，标记「估」。
- 输出 `index/standards_index.json`；正文缓存 `.cache/standards_text/`。

实测：

- 50 本标准，37 本有目录；核心 7 本全部覆盖。
- GB 50007：46 条，偏移 +9（high）。
- JGJ 94：53 条，偏移 +5（high）。
- GB 50011：80 条，偏移 +17（high）。
- GB 50021：73 条；JGJ 79：43 条；GB 50330：46 条。

### API / UI

- `/api/standards/index`、`/toc`、`/locate`、`/search`、`/page`。
- 「规范」顶部：选规范 → 章节树；输入 `5.2.4` 定位到 5.2 节；
  点章节打开 App 内页图（无需下载 PDF）。
- 错题详情的规范引用带 `locate`：点击打开章节页；无索引时退回原 PDF。
- 页图支持上一页/下一页/跳页/放大/原 PDF。

## 纸面打印中心

### `app/print_export.py`

- `writing_scale`：手写区标准/更多/最多（0.6–1.8）。
- `result_boxes`：每题底部印「对 □ 错 □ 放弃 □ 超时 □」。
- `cover`：封面任务单 + qid 清单 + 结果回填表（两列）。
- JPEG 输出：默认 220 dpi q85，30 题从 ~396 MB 降到 ~28 MB。
- 页眉自动区分题面/答案；封面不计入页码。

### API / UI

- `/api/print?scope=plan`：按未完成原型选 30 题，生成「本周任务卷」。
- 打印中心新增：本周任务卷 / 当前筛选 / 最近 7 天 / 今日复习，
  封面、回填格、手写区选项。
- 计划页/错题本都能打开打印中心。

### 纸面工作流

1. 打印任务卷：题面在前，答案单独在后（封存）。
2. 纸上限时做，手机只拍照/记录。
3. 做完照封面「结果回填」把四个数录进 App。
4. 错题拍照或手动记入错题本；复习按排期走。

## 照片存储

- 新照片：长边压到 **2400 px**，JPEG q85；缩略图 480 px q78；仍按 sha256 去重。
- 过程照片默认每题保留最近 2 张；设置页「照片存储」显示总占用，可一键清理：
  清理前自动 zip 备份，标记原图（`attempts.photo_id`）永不删除，旧 review_log
  引用置空后再删孤儿文件。
- API：`GET /api/storage`、`POST /api/storage/prune`（必须 `confirm: true`）。
- 现有老照片不重新编码（二次压缩会降质）；靠「保留最近 N 张」控制增量。

## 限制 / 下一步

- 练习记录是聚合四数，不是逐题；按原型/知识点的正确率来自错题本+记录，
  不是完整答题日志。
- OCR 目录对部分标准仍有缺节；索引标「估」的页码需要翻一页确认。
- 图/公式多的案例题，一页一题、手写区很大；打印成本高但适合验算。
- 基线阶段「本周任务卷」不是主任务，先交基线；阶段进入基础期后再按周题量打印。
- 书签贴纸（规范侧边标签）尚未生成；可作为下一步打印功能。
