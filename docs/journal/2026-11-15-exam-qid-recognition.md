# 真题题号识别：A2025-A-7 不再漏读

2026-11-15 · bug fix

## 症状（_ming 实测反馈）

拍照识别错题时，真题的编号认不出来，例如 App 打印卷面上的 `A2025-A-7`。
习题册的 `3-11` 正常，真题卷的题号一个候选都没有。

## 根因

两道门都只为「篇-题」设计：

1. **候选正则**只匹配 `数字-数字`（`ANCHOR_RE` / `LOOSE_RE` / `BARE_RE`），
   `A2025-A-7` 以字母开头，整条路进不来。
2. **校验表**用 `load_valid(当前册)` 取 `lookup["chapter"]` 的裸键（`4-12`），
   真题号根本不在这个集合里；`family` 也只给 C/Z。

打印卷的题号标签（`app/print_export.py` → `Sheet.add`）印的就是完整题号，
所以拍出来的那条文字是 `A2025-A-7 · 来源：2025案例A 第 12 页`。

## 决定

1. **真题号是自描述的，不需要「当前册」。**
   `A2025-A-7` 自带年份、场次、题序；`K2025-P-68` 自带知识卷前缀；
   `M2-13` 自带模拟套号。同一张打印卷可以混着 C/Z/A/K/M，按当前册前缀
   反而会串册。识别层直接输出完整键，`normalize_qid()` 已经原样接受。
2. **一律用题库真键校验，不做格式猜测。**
   新增 `load_self_describing()` 缓存 `lookup["exam"]` / `lookup["mock"]` 全键；
   候选只有命中真键才出。OCR 掉一个横线（`A2025A-7`）、掉两个（`A2025A7`）、
   横线变 `—`/`一`/`·`/`.`/全角，都能还原；还原不了的直接丢，不会造题。
3. **模拟号掉横线只在唯一拆分时采纳。**
   `M213` 可能拆成 `M2-13` / `M21-3`；两键都在库里说明有歧义，宁可不给，
   也不猜。唯一命中给 `bare`，不参与自动打开。
4. **真题号命中即 `start`。**
   与习题册标签同级：单题页仍走 `auto_qid` 自动打开；整页多题按页序全部勾选。
   书脊上的手写/杂线粘在左边时降为 `loose`（`p=A2025-A-7` 也能选，但不自动开）。
5. **自描述题号的字符区间对其他通道屏蔽。**
   `M2-13` 自带 `2-13`，旧逻辑会把它当成本册题号再出一次；
   现在标签覆盖的区间先记下，`LOOSE_RE` / `BARE_RE` / `BARE_STEM_RE`
   落在区间内一律丢弃（同一行里另起的 `3-11` 不受影响）。

## 实现

- `tools/recognize_qid.py`
  - `EXAM_RE` / `EXAM_ANY_RE`（A/K + 4 位年份 + A/P 场次 + 题序，两个分隔符
    可缺省）；`MOCK_RE` / `MOCK_BARE_RE`；
  - `load_self_describing()`：进程内缓存 exam/mock 全键；
  - `qid_candidates(text, valid, exam_keys, mock_keys)`：自描述题号先匹配、
    本次调用内去重、并把覆盖区间通报给其他通道；`recognize()` 默认加载
    真键表并把集合传进候选层；
  - `_FULLWIDTH` 补全角 `ＡＫＰＭａｋｐｍ`；`DASH` 补 Unicode 减号 `−`。
- `app/static/index.html`：手输占位符与提示补充 `A2025-A-7`。
- `docs/usage.md`：拍题一节写清两种印法，以及「原版真题书只印 7.」的限制。
- `tests/test_recognize_exam.py`：32 条（印法 / OCR 变体 / 去横线 / 全角 /
  括号 / 前导零 / 未知键拒绝 / 模拟唯一拆分 / 区间屏蔽 / 无索引兜底 / auto / 真键表）。

## 验证

- **pytest 317 条全绿**（新增 32 条）。
- 旧日期守卫 11 条不回归：`2024-11-14`、`24-11-14`、`2024年11月14日`、
  `2024-11` 仍不产生候选；`3-11` / `4-11` 正常。
- 用真实 RapidOCR 跑合成打印卷样张（`.probe/exam_label_check.py`）：
  `A2025-A-7` score 1.00 `start`、`M2-13` 0.95 `start`、`C4-12` 仍按当前册
  出 `4-12`；整页三题 → `auto=None`（多题不自动打开），候选全部可勾。
- 下游不变：`/api/resolve`、`/api/crop`、记错、复习、打印都走 `normalize_qid`
  的完整键路径，`build_crop` 早已支持 A/K/M 的题面与答案页。

## 限制

- 原版真题书页只印 `7.`，页边竖排的「2015年案例（下午卷）」不进识别层；
  拍原书时无法知道是哪年哪场，需要手输或在 App 里打印成卷再拍。
  若以后要支持，入口应是「先选年份+场次，再拍题序」，而不是猜。
- 打印卷上的 `C4-12` 仍按「当前册」还原（`C` 前缀会落成 `4-12` 的 loose 读），
  当前册选错时会串册；真题号不受这个限制。
