# M7 应用内 2025 基线记分（2026-11-02）

北极星：11-04 交基线时只带手机和纸卷，不在电脑上跑 CLI。

## 决定

- **数据库是主记录，CLI 降为回填工具。** `baseline_runs` + `baseline_items`
  存两半；仪表盘、统计、计划都先读数据库，只有数据库为空时才读
  `docs/coach/baseline-2025.md`。
- **四个数是评分口径，逐题状态是可选细节。**
  - 作答 / 做对 / 放弃 / 超时由人工按过程自评；`作答 + 放弃 = 25`。
  - 25 题全部逐题录入时，四个数自动从逐题状态计算并锁定输入框。
  - 只录一部分时，四个数以手填为准；逐题只贡献分项统计，并显示覆盖率，
    服务端拒绝「逐题对/错/弃/超时」超过四个数的记录。
  - 案例不读 A/B/C/D 选项；做对 = 过程与结果均正确。
- **半分与合计分开显示。** 每半 25 题 × 2 分 = 50；两半齐后合计 100、
  通过线 60，避免拿半卷 50 分制去对 60 分线。
- **一次基线同时进练习台账。** 保存/修改同半会 upsert 同一条
  `practice_sessions`（`baseline_half` 唯一索引），所以周计划不会重复计数；
  在「最近练习」里删除基线记录会被拒绝，必须回基线页删。
- **半卷级答案纸照片**（可选）挂到 `baseline_runs.photo_id`；逐题过程照片
  仍走错题本，不在基线页重复拍 25 张。
- **错题入本是一等动作。** 逐题标记为「错」的题可一键进错题本，
  `skip_existing=True` 保证重复点击不重复计次，进本后按 M3 排期。
- **错因只做可选细化。** 标记「错」后可补「过程对·结果错 / 过程错 / 没思路」，
  不选不猜；「对」自动记为「过程对·结果对」。

## 数据与接口

- `baseline_runs(year, half UNIQUE)`：日期、用时、四个数、逐题数、备注、照片。
- `baseline_items(run_id, qid PK)`：题号、序号、类别、结果、超时、过程状态。
- `practice_sessions.baseline_half`：半卷台账一对一；schema_version 5。
- `GET /api/baseline`：两半、50 题清单（只含题号/序号/九大类，不含选项字母）、
  分项、合计、通过线。
- `PUT /api/baseline/{A|P}`：保存或修改半卷，返回基线 + 计划。
- `DELETE /api/baseline/{A|P}`：删半卷及其台账行。
- `POST /api/baseline/{A|P}/wrongs`：错题入本，幂等。
- 深链：`/?tab=data&view=plan&baseline=A` 直接打开上午卷记分。

## 页面

- 「计划」页顶部两张半卷卡：状态、得分、四个数、逐题覆盖、九大类分项、
  错题入本数量；未录入的卡直接「录入记分」。
- 记分抽屉：题面 PDF、日期/用时、四个数、25 行「对/错/弃 + 超时」、
  错题的过程状态、答案纸照片、备注；「删除本半」「保存记分」。
- 首页基线行动卡改为「去基线页」；两半齐后自动消失。统计页基线卡给出入口，
  不再提示运行 CLI。

## 已知缺口

- 同一半只保留最近一次记录，没有多次基线历史；需要重考就改同一条。
- 逐题只支持结果/超时/过程状态，不支持逐题照片与逐题备注。
- 分项统计按「已录题」计，未录题不会被推断；界面用「逐题 n/25」明确覆盖。
- 知识卷基线（K 族）不在本模块；现在只服务 2025 案例两半。
