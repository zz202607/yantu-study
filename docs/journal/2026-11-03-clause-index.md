# 2026-11-03 · M12 考前依据清单（条文反向索引）

## 问题

M11 解决的是「这道错题在规范哪一条」。考前真正要的是反过来：
**一条条文 → 我有哪些错题落在它下面**。原来只能逐题点开详情、自己抄，
错题一多就无法汇总成一张「考前依据清单」。

## 决定

1. **不重新 OCR。** 反向索引只读 M11 已有的三种来源（M4 解析缓存 / 原型 /
   关键词）；打开清单毫秒级返回。用户看过的解析越多，精确行自动变多。
2. **两个桶，不混。** `exact` = 解析里直接写出的标准号与条文；`suggested` =
   原型/关键词推出来的复习范围。两段标题、说明、排序都分开，建议永不冒充引用。
3. **节级归并。** 精确行按解析定位到的节（5.2.4 → 5.2）；建议行保留伴读站的
   节区间（`5.2/5.3` 不拆），否则同一道桩基题会在 5.2 和 5.3 各数一次。
4. **同一标准已有精确依据时，不再为该题出同标准的建议。** 精确证据优先，
   建议只填还没定位的标准；这样两个桶里的题不会重复。
5. **单节建议并入同节精确行**（如 GB 50007 5.2 一行 9 题：3 解析 + 6 原型），
   避免同一节出现「精确行/建议行」两行。
6. **未命中与未解析都显式列出**：3 道题没有任何条文、1 条解析引用没收录页码，
   都出现在清单底部，不静默丢弃。
7. **已掌握默认隐藏**，可切「含已掌握」；行内题号点开错题详情，条文点开本机
   规范页图；同一题可以出现在不同条文下（清单按条文组织，不按题去重）。
8. **三个入口**：数据页第 7 个 tab「依据」、错题本「依据清单」、M11 详情面板
   底部的「考前依据清单」。

## 数据与实现

- `app/clauses.py`
  - `reverse(attempts, include_mastered=False)`：把每次 `hints()` 的三种来源
    归并成节级行，输出 `summary / exact / suggested / unmatched / unresolved`；
  - `_row_tokens` 只拆精确行的节号；`_clauses_for_token` 按节过滤条文；
  - `_finish_row` 统计每题来源（answer/prototype/keyword）与掌握数；
  - 精确行的节标题优先取手工伴读站名，避免 TOC 里的
    `General Requirements`、`液化士` 这类扫描/OCR 名直接上屏。
- `app/server.py`：`GET /api/clause-index?include_mastered=0|1`；
  `_all_attempts()` 以 200 条一页取全，不受列表默认上限影响。
- `app/static/index.html`：新数据 tab「依据」；摘要四格、两段清单、题号 chips、
  条文行按钮；390/320 宽均无横向溢出。
- **254 条测试全绿**（新增 6 条：精确/建议分桶、区间不拆、同标准不重复建议、
  未命中不丢、未解析带题号、每条都有可打开页码）。

## 验证

- 真实 34 道错题：31 道定位成功，3 道未定位（`A2025-P-19`、`C3-6`、`C4-4`）；
  清单 20–22 行，随 M4 缓存增减；生成耗时 **0.05 s**。
- API 实测 200；`include_mastered` 用临时库验证：included 34 → 33、
  隐藏已掌握的 `A2025-A-24`，切回 34 恢复。
- 无头 Edge（390×844 与 320 宽）0 横向溢出、0 JS 异常；
  点首行打开 GB 50007 p30「5.2 承载力计算」，点题号打开 `A2025-A-24` 详情，
  详情面板「考前依据清单」可跳回该 tab。
- 真实分布：GB 50007 5.2 9 题（解析 4 / 原型 5）、GB 50007 4.1 6 题、
  JGJ 94 5.2 3 题、JGJ 94 5.1 2 题、GB 50025 4.4 2 题；
  桩基建议行 `5.2/5.3` 7 题、`5.4` 5 题，没有把同一题重复塞进两个节。

## 已知缺口 / 下一步

- 建议层按伴读站组织，跨度大的站（如 JGJ 94 5.2/5.3）会把同一题放进多个站；
  清单已注明「同一道题可能出现在多个条文下」，不做强行去重。
- 解析未缓存的题只有建议，没有精确条文；要精确需先在详情/复习里暖 M4。
- 目前只在 App 内查看，没有按标准筛选或导出 PDF；考前若要打印，可作为下一步。
- 反向索引不触发 OCR，页面打开速度稳定；代价是首次打开时 exact 行可能偏少。
