# 2025 基线卷与评分器（2026-11-02）

北极星：一年的备考要有起点。11-04 要做 2025 案例上午/下午两半、各 3 小时、
按考场规则记录四个数。操作系统的原件已删、只剩 `compressed/` 扫描件，所以
这次把「卷子」和「记分」两件事都做成工具，基线当天不需要任何手工排版。

## 卷子：`tools/print_baseline.py`

- 直接读 `index/tags/A2025.json` 的 50 个题号，按考试顺序排两本：
  `print_samples/baseline_2025_A.pdf`（上午）、`_P.pdf`（下午）。
- 复用 M3 的 A4 排版：题面在前、答案在后，每题原生物理尺寸 + 均分手写区。
  - 上午 25 题 → 题面 17 页 + 答案 13 页；下午 → 16 + 12；各约 24.5 MB。
  - **只打题面页**（上午 1–17、下午 1–16），答案页封存到两半都做完。
- **图像压缩 220 dpi JPEG q85**：`make_print_sample.Sheet` 新增可选 `jpeg=(dpi, quality)`，
  默认仍走无损 PNG。原来 2 题样张就 40 MB，50 题会到几百 MB；
  220 dpi 下正文、表格、公式、图清晰（110 dpi 渲染抽检通过）。
- 顺带清理卷头：`_short()` 去掉【…】、年份、扫描后缀，题号行只留 `A2025-A-7`，
  书名和页码放在「来源」里，不再重复两遍。`export_pdf(..., jpeg=)` 是新参数。

## 记分：`tools/score_baseline.py`

- 输入 25 个字母（A/B/C/D，放弃用 `-`），对照 `A2025.json` 的答案：
  - 四个数：作答题数 / 做对数 / 放弃数 / 超时题数（后两个可显式给，放弃默认数 `-`）；
  - 得分 = 做对 × 2（案例每题 2 分，合格线 60/100）；
  - 九大类分项正确率 + 错题清单（你选 vs 答案）。
- `--write` 追加到 `docs/coach/baseline-2025.md`；同日同一半拒绝重复写，避免覆盖。
- 输入串容错：空格/逗号/换行忽略，长度和字符不对直接报错，不猜。

## 验证

- 单测 **82 条全绿**（新增 7 条：答案解析、分项统计、四个数渲染、重复小节拒绝）。
- 两本 PDF 生成 18 s/本；抽检题面文字页、带图题、答案页均清晰可读。
- 评分器用全 C 假答案冒烟：24/25 作答、12 对、分项表与错题清单正确。

## 有意没做 / 已知缺口

- 只支持案例（单选 A–D）；知识卷是多选 + 不同分值，基线不涉及。
- 超时题数靠用户自己记，工具不埋计时。
- 分项正确率只是描述统计，不自动给「该练哪类」的结论——等两半数据齐了一起看。
