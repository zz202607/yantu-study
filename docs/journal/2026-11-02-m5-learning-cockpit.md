# M5 学习驾驶舱：倒计时、统计、规范联动与 App 形态

日期：2026-11-02 · 状态：完成（120 条测试全绿，逐屏截图验收）

## 为什么做

M1–M4 解决的是「查得到、记得下、能复习」，但首页仍只有拍照入口，
用户感受是「一个资料库」。这次把已有数据组织成每天能用的驾驶舱：

- 打开就能看到离考试几天、今天做什么、我弱在哪；
- 统计按九大类 + 细到节，和考试权重、2025 基线对照；
- 题目能一键连到核心规范 PDF 和工程地质手册页；
- 鼓励语必须由真实复习日志生成，不能空喊。

## 做了什么

### 后端

| 文件 | 作用 |
|---|---|
| `app/curriculum.py` | 十篇/九大类静态课程表：权重、核心/配套规范、手册页码范围、原型关键词；A2025 类别映射 |
| `app/settings.py` | `data/settings.json`：考试日期、名称、备考起点、每日目标、基线计划日；原子写、严格校验、损坏回退默认 |
| `app/analytics.py` | 学习快照 → 首页/统计：倒计时、连续天数、今日、九大类、70 节、错因、14 天活动、里程碑、下一步、证据型鼓励；2025 基线 markdown 解析 |
| `app/standards.py` | 规范库扫描/编号规范化/编号优先匹配/安全按名取文件；手册全文索引、书签、搜索、页图渲染 |
| `app/store.py` | 新增 `learning_snapshot()` 只读快照；备份/恢复纳入 `settings.json` |
| `app/server.py` | `/api/home`、`/api/stats`、`/api/settings`、`/api/standards`、`/api/standards/file`、`/api/handbook/{meta,search,toc,page}`、`/api/baseline/file/{A,P}`、PWA 静态路由；详情/建议补类别与规范链接 |

关键数据口径：

- 正确率只来自 `review_log` 窗口内 correct / (correct + wrong)；
  没有复习记录显示「—」，不用单次 `last_result` 冒充。
- 九大类：C2–C10 直接映射；C1 土力学单独列出、考试权重 0；
  A2025 题按 `index/tags/A2025.json` 映射；K/Z、非 2025 真题进「未归类」。
- 细分知识点：按 `chapters.json` 的节区间映射；题号落在节间空隙时归到最近的
  前一节（OCR 区间不完美，不能因此丢掉统计）。
- 手册页码统一用 PDF 页（书签口径），界面明确标注，避免和印刷页码混淆。
- 规范匹配先按规范化编号（`GB/T`→`GBT`、去空格/年份），再按书名；
  书名命中不唯一时放弃，宁可不开错书。

### 前端

- 首页重做为驾驶舱：倒计时 Hero、三项核心数字、里程碑进度、今日复习 CTA、
  证据型鼓励、下一步行动卡、知识分布条、快捷入口。
- 底部 5 栏导航：首页 / 拍题 / 错题 / 复习 / 数据；错题与复习带数量角标。
- 「数据」页三个子页：
  - 统计：7/30/90 天、九大类表、细分知识点、错因、14 天活动、覆盖、基线；
  - 规范地图：可搜索类别/规范号，核心/配套规范直接开 PDF，手册范围直接开页；
  - 手册检索：全文搜索、书签快捷入口、结果高亮、页图查看/翻页/跳页/放大。
- 错题详情新增「规范定位」「手册查这题」；M4 的规范引用变成可点击链接。
- 查题页新增「规范」按钮（有类别时出现）。
- 设置 sheet：考试日期/名称/每日目标/基线日；保存后首页立即刷新。
- PWA：manifest、192/512/maskable 图标、apple-touch-icon、sw.js（仅安全上下文注册）；
  设置页说明局域网 HTTP 下需手动「添加到主屏幕」。
- 深链：`?qid=`、`?tab=review|lookup|book|data&view=stats|standards|handbook&q=...&cat=C3`。

## 失败与限制

- **PWA 自动安装**：局域网 `http://192.168.x.x` 不是安全上下文，Chrome 不弹安装；
  manifest 和添加到主屏幕仍可用。要独立 App 需要 HTTPS 或原生壳。
- **规范 PDF 体积**：单本 5–100 MB，手机端打开受 Wi-Fi 影响；只提供原文件，不做转码。
- **手册 OCR 噪声**：检索只用于定位，引用仍看原图；这是既定原则。
- **基线记分仍在 CLI**：手机端目前只下载试卷；案例按过程自评四个数，
  不按选项字母判分（见 `docs/objective-scoring.md`）。
- **考试日期默认值**：2027-11-01 是估算，官方日期公布后需在设置改。
- **K/Z/非 2025 真题**：无九大类标签，统计单列「未归类」，不硬猜。
