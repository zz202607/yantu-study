# M9.2：限时拆解与认题卡（2026-11-02）

北极星：四象限已经指出瓶颈是「会但慢」和「看到不熟就跳过」。这一块把清单
变成带计时器的训练，不再新增数据采集。

## 做了什么

1. **限时拆解**：从基线的「会但慢 / 放弃·没时间 / 做错」或某个原型区间抽
   5–10 题；每题 8 分钟硬上限（可改 5–15 分钟）。
   - 每题先写「首步卡」：先查哪本规范 / 先列哪几个量；
   - 结果四选一：做对 / 做错 / 超时 / 放弃；
   - **放弃必须已写首步**，客户端和服务端都拦；
   - 计时到 0 后「做对 / 做错」禁用，只能记超时或放弃。
2. **认题卡**：5–10 题，每题 30 秒，只认原型与主规范，不做题。
   - 来源：弱项原型 / 核心 A+B / 全部 / 单个原型；
   - 提交后立即显示正确答案与对错；
   - 原型与规范分别判分，规范不唯一时只判原型。
3. **会话与台账**：
   - 队列在开始时冻结，中途退出可继续；从第一道未记录的题恢复；
   - 限时拆解完成后写一条 `practice_sessions`（source=`drill`），进入周计划；
   - 认题卡**不写题量台账**，只保存在 `drill_sessions` / `drill_items`；
   - 最后一题记录后自动结束；重复结束/重试不会重复写台账。
4. **界面**：计划页「把清单变成训练」两张卡；全屏计时面板；进度 n/N；
   对答案不重置计时；结束后一页汇总（四类结果、首步覆盖、平均用时、一句判断）。
   首页行动卡也接入：基线完成后直接出现「限时拆解 N 题」，点击跳到训练区。

## 关键决策

- **认题真值来自 `PROTOTYPE_RANGES`，不靠模型猜**：题号区间本身就是答案。
  B5 区间包含在 B4 里，所以接受 B4/B5 两个答案，展示更具体的 B5。
- **主规范只在课程核心列表唯一时出题**：A1–A8、A9–A11、A15–A17、B1–B8、
  C/D 组都有唯一主规范；冻土、滑坡、泥石流不硬塞规范号，只判原型。
- **限时拆解进题量台账，认题卡不进**：30 秒认题是另一种能力；若按题量计，
  周计划会被“假刷题”灌水。两种训练共用会话表，但只有计时做题写台账。
- **放弃也要写首步**：案例按过程给分，考场上写两行就有过程分；这条约束
  把「不会就跳过」改成「不会也留下可得分的第一步」。
- **计时用绝对 deadline**：看答案、重渲染、切前后题都不会重置 8 分钟；
  超时后只允许记超时/放弃，避免“手慢但点做对”。
- **队列冻结 + 首未记录恢复**：训练中途关页不会丢已记的题；恢复的那一题
  重新计时（没有逐秒落库，不假装知道上次已用多久）。
- **唯一索引防重复台账**：`practice_sessions.drill_session_id` 唯一；
  最近练习里禁止直接删训练台账，必须回训练页重做，避免半套数据。
- **认题轮换**：同一来源下从 `drill_history_qids` 取已用题并跳过，
  下一组自然换题；同一原型有足够题时不会重复。

## 验证

- 单测 **222 条全绿**，新增 `tests/test_drill.py` 19 条 + 首页训练行动 1 条：区间真值、B4/B5 重叠、
  三类清单顺序、未分流提示、放弃首步校验、自动结束、台账唯一、认题评分、
  轮换、认题不计题量、概览计数。
- 真实 API（临时库 + 2025 基线造数）：四象限 10/5/5/5，分流后
  `counts {slow:5, skipped:3, wrong:5}`；限时 5 题 → 台账
  `drill 4 答 / 2 对 / 1 超时 / 1 弃 / 16 分钟`。
- CDP 无头 Chrome：计划面板、认题卡 8 题、限时 5 题、汇总、再练一组全通；
  超时边界（00:00、正确/错误禁用）、放弃空首步拦截；0 个 JS 异常。

  `m9-drill-summary.png`（未入库）。
