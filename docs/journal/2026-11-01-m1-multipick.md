# M1 收尾：拍整页多题勾选（2026-11-01）

目标：整页照片认出多题后，一次勾选、连续看题面/解析。原则不变——不猜题号。

## 做了什么

- 候选打包规则从 `app/server.py` 挪进 `recognize_qid.pack_candidates`，与 `auto_qid` 同住：
  - 所有 `start`（行首锚定 + 已在当前册题号集合里）**全部保留**，不受噪声阈值/名额外挤掉
  - 非 start 只留 ≥0.55 的前 8 个，作为手点兜底
  - 按检测框 y 排序 = 纸张从上往下；页面与基准共用这一份规则
- 候选改成可勾选：默认勾选全部 `start`（整页照片 = 本页全部题）；
  `待确认`（loose / bare / suffix）不预勾，点一下才进批次
- 跨两阶段不丢勾选：
  - head 阶段已勾的题保留
  - full 阶段新发现的 `start` 自动补勾（行头通道常漏一题，靠滑窗补）
  - 用户明确取消的题号进 `off` 集合，之后任何阶段都不再自动勾回
- 批量查看器：题面/解析、上一题/下一题、进度 n/N、←/→ 方向键、相邻题裁图预取；
  「回候选」保留勾选，方便改错勾；批量模式下隐藏「再拍」，避免误弃整批
- 单题路径不变：唯一高置信 start 仍自动打开；手输仍走单题
- 390 px 手机上四个按钮排一行（`#viewer .toolbar` 收窄 gap 与内边距）

## 验证（都是真实数据）

- **18 张真图基准**：候选召回 17/18，**打包后召回仍是 17/18**；自动入库 6/6 全对；
  平均 5.01 s（提速后是 4.97 s，持平）
- **整页渲染测试**（`.probe/page_shot_check.py`）：C 空白册 2 题页 / 4 题页、Z 知识册 5 题页，
  全部题号以 start 出现在打包候选、按纸张顺序自上而下 → PASS
- 多题照片 `4-12 4-13错.jpg`：4-12 是 start 自动勾；4-13 被手写粘连读成 `8.504-13`，
  只能算 loose(0.83)，显示「待确认」需手点一次 —— 符合「宁可多问一次，不记错」
- **真浏览器验证**（Edge headless + CDP，脚本与截图在 `.probe/m1-multipick/`）：
  两阶段模拟、勾选跨阶段保留、批量 1/2 → 2/2、回候选勾选不丢、390 px 布局
