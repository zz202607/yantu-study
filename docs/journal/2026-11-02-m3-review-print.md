# M3 复习与打印卷 · 零决策复习、会话续做、Z 遮罩、A4 导出（2026-11-02）

北极星不变：拍 → 做 → 对答案。M3 把「错题本」变成「到点会自己出现的复习队列」，
并把筛选结果变成可打印的题面/答案分卷。

## 排期规则（写死，不引入 SRS 算法）

- 记错 → 1 天后复习；若上次间隔已经 >3 天（长间隔后的反复错）→ 3 天。
- 做对 → 间隔按 7 → 15 → 30 天上升；错次不改（`times` 只在「记错/复习做错」时 +1）。
- **掌握**：连续 2 次做对，且两次之间真实间隔 ≥7 天。只做对一次、或三天内抢答两次都不算。
- **顽固**：错 ≥3 次；复习结束页提示回书/规范，不再机械刷。
- 手动「恢复未掌握」会重置 streak 并把 `next_at` 设为现在，立刻回到队列。

## 今日队列

- 组成：到期（`next_at <= now`）→ 最近 3 天新错（`reviews=0`，即使明天才到期）→ 最多 3 道顽固题。
- 每桶内按章 round-robin 交错，避免一整个晚上只刷同一篇；硬上限 **20 题**。
- 已掌握默认不复出现（「错题复活」留到 v2）。

## 会话与撤销

- `review_sessions` 冻结当天队列（qids + cursor + started/finished），关页后回来接着做；
  同一天未完成的会话优先续做，完成后可再开新一轮（如果没有到期题则只回总结）。
- `review_log` 记录每次评分的前后状态（间隔/streak/status/times/next_at/标签），
  `UNIQUE(session_id, qid)` 让**重复提交不会重复改期**。
- 撤销 = 回滚最后一条 log + cursor 后退；排期和标签一起恢复。E2E 已验证。
- 跳过只推 cursor，不写 log、不改排期；本轮不再出现。

## Z 族答案遮罩

- Z 册题目、答案、解析同页。复习时先把裁图按 `【答案】` 行的 OCR 框拆成题面/答案两半，
  题面阶段**根本不请求答案图**；检测失败返回 409，页面提示跳过，不泄露。
- 缓存命名必须分开：遮罩答案是 `Z1-10_ma.png`，查题页整页答案是 `Z1-10_a.png`。
  开发中曾共用 `_a`，导致查题页可能拿到拆过的答案；已改后缀并清掉本次生成的脏缓存。
- 打印卷复用同一拆分逻辑（`tools/crop_question.py:split_z_answer`），
  `make_print_sample.py` 的旧实现改为薄包装，行为不变。

## A4 打印卷

- `app/print_export.py` 复用 M0 的 `Sheet` 两遍排版：题面页在前、答案页在后，
  默认原尺寸（最大 125%）+ 每题手写区；Z 题面只放题，答案进答案页。
- `Sheet` 增加**每题手写区下限**：C/A/M 150 pt，Z/K 60 pt；页内剩余空间均分。
  统一下限时与旧算法逐点一致，M0 的打印结论仍成立。
- 入口：错题本「打印卷」→ 当前筛选 / 最近 7 天 / 今日复习（≤30 题，2 次点击内出卷）；
  复习结束页「打印这一卷」1 次点击。
- 生成物在 `data/exports/`，7 天自动清理；PDF 内嵌 300 dpi PNG，质量优先，文件很大
  （6 题混合卷约 166 MB，M 族 3 题约 278 MB，与 v10 样张同量级），本地打印可接受。
