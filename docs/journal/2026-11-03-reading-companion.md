# 2026-11-03 · M10 规范伴读

## 问题

题库和复习闭环已经有了，但「看规范」仍然是从第一页翻到最后一页，或者只在错题后
零散跳转。考生真正缺的是：**按考试权重排好的短路线 + 到页 + 知道该看什么**。

## 决定

1. **做路线，不做教材。** 9 本高频规范、67 站；每站 6–18 分钟，只给
   「为什么考 / 先看哪几条 / 最容易错 / 30 秒自检」，不重写条文。
2. **页面用标注版原页。** `4标注版核心规范` 的红字和红线本身就是老师留下的重点；
   保留原页比任何二次总结都可靠。
3. **不为 67 站手填页码。** 标注版是 2-up 扫描、无文字层、目录页与正文页号重复；
   写 `tools/build_annotated_index.py`：页脚 OCR 取锚点 → 识别正文起点 → 插值 →
   附近 OCR 校验；校不上就保留插值并标「估」。
4. **进度落 SQLite。** `reading_progress`（每站一行、累计秒数、笔记）+
   `reading_log`（每次访问）。推荐规则：继续最近读的规范；`review` 优先于未读。
5. **入口放首页。** 驾驶舱新增「规范伴读」迷你卡：已读站数、本周分钟、下一站；
   数据页新增「伴读」标签；深链可直达某站。

## 数据

- `app/reading_data.json`：9 本、67 站；页面用印刷页号，正文条目全部来自
  `index/standards_index.json` 的目录页（JGJ 120 / GB 50025 / GB 50330 的目录
  在索引里是书签级，页码按原书目录核对过）。
- `index/annotated_index.json`：标注版 PDF 的正文起点、页脚锚点、每站 PDF 页、
  估算站列表。
- 练习题号区间取自 `docs/coach/prototypes.md`，落库前用 `index/lookup.json` 校验。

## 验证

- 阅读数据完整性测试：9 本 / 67 站、站点唯一、页号为正、分钟内 5–20、
  有 why/pitfall/check/look_for、练习题号存在；有目录的规范站点必须在目录里。
- GB 50007 标注版抽检：3→p22、4.1→p28、5.2→p37、5.3→p42、5.4→p47、
  6.7→p61、8.1→p77、9.3→p121、附录K→p151；`p37` 页眉为 `5.2 承载力计算`，
  与印刷页 21 一致。
- API：`/api/reading`、`/api/reading/GB50007-2011`、页图接口、
  `POST` 保存、首页 `reading` 字段全部返回 200。
- 无头 Chrome：伴读首页、单本路线、5.2 阅读站（计时、页图、条文 chips、
  练习题、笔记、两个状态按钮）逐屏渲染通过；页面无横向溢出。
