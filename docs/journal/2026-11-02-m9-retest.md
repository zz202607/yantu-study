# M9.3：2024 整卷打印与复测（2026-11-02）

北极星：6 周训练要有一个未见过答案的整卷检验。2025 已作为基线烧掉，
12 月中改用 2024 卷；打印、记分、周计划回填要在一个闭环里完成。

## 做了什么

1. **2024 整卷打印**：新增 `tools/print_exam.py`，从 `index/lookup.json` 取题，
   生成 `print_samples/exam_2024_{A,P}.pdf`。
   - 题面页在前、答案页封存；封面一页：规则 + 25 题结果回填格。
   - 上午 32 页 / 25.2 MB，下午 32 页 / 24.7 MB；220 dpi JPEG。
2. **整卷复测入口**：计划页新增「整卷复测 · 2024」。
   - 两半卡片显示分数/四个数/正确率；题面 PDF 直接下载。
   - 「录入复测」只收四个数：作答、做对、放弃（自动 = 25 - 作答）、超时；
     再加上日期、用时、备注。
   - 两半齐后显示合计 100 / 通过线 60 / 正确率；删除记录时练习台账一起回滚。
3. **API**：
   - `GET /api/retest?year=2024`：整卷记录 + PDF 是否就绪。
   - `PUT /api/retest/{year}/{half}`：只收四个数；带逐题 items 会被拒绝。
   - `DELETE /api/retest/{year}/{half}`。
   - `GET /api/retest/file/{year}/{half}`：只允许 2018–2024 且文件存在。
4. **练习台账按年隔离**：`baseline_half` 从 `A/P` 改为 `2025-A / 2024-A`；
   schema v8 迁移把旧值补成 `2025-A`。这样 2024 复测不会覆盖 2025 基线的台账行。

## 关键决策

- **复测用 2024，不再动 2025**：2025 是一次性的基线烧卷；12 月中复测必须用
  没做过、答案没看过的卷，否则分数没有信息量。
- **复测只记四个数，不做逐题/分项**：2024 卷没有逐题类别标签；硬造分类会把
  「猜的分类」混进统计。四个数足以判断是否过线，分项留给以后有标签的卷。
- **复用 `baseline_runs` 而不是新建表**：它本来就是「整卷记录」，UNIQUE(year, half)
  天然支持多年；只需把练习台账的键从 half 改成 year-half。
- **台账键必须带业务范围**：旧键只用 `A/P`，第二年复测会覆盖第一年基线；
  迁移时把旧行补成 `2025-A`，唯一索引保持不变。删除半卷时同步清掉
  `baseline_triage`，避免旧分流污染重做。
- **打印题号来自 lookup，不来自手写清单**：过滤 2021-P 的幻影题号 0，
  要求题号连续且满足当年题量（2018+ 25 题，2017- 30 题），缺页直接报错。
- **封面带结果回填格**：25 题对/错/弃/超时逐题勾选，做完直接照封面录 App，
  不在手机上翻 32 页找题号。

## 验证

- 单测 **230 条全绿**：新增 3 条跨年台账/迁移/复测拒绝逐题 + 4 条打印题号选择
  + 1 条删除半卷清理旧分流
  （连续、幻影 0、缺题、题量不符）。
- API 冒烟（临时库）：2024 A 20 答/15 对 = 30 分；P 22 答/16 对 = 32 分；
  合计 62/100 过线；2025 基线仍 60；删除 2024-A 只回滚 `2024-A` 台账，
  `2025-A/P` 与 `2024-P` 不受影响。
- PDF 实测：两本各 32 页、约 25 MB；封面/题面/答案三处抽检，HTTP 200 `application/pdf`。
- CDP 无头 Chrome：复测卡片、PDF 链接、录入弹层、放弃自动计算（25-20=5）、
  保存、合计 62/100、再次打开预填、删除按钮出现，0 JS 异常。

## 还没做

- 复测只支持 2018–2024（2018 起每半 25 题）；2015 在 lookup 中缺号，无法打印。
- 没有逐题状态/分项/答案纸照片；要分项得等有类别标签的卷或人工补标签。
- 没用 2024 卷做实际考试；12 月中再打印或直接打印已生成文件。
