# M4 答案页按需 OCR · 规范条文与错因候选（2026-11-02）

北极星不变：拍 → 做 → 对答案。M4 只做一件事：**给已经进错题本的题读解析**，
抽出《规范》+ 条文号和点评里的易错提示，给出可点选的错因候选。
不读新题、不批量 OCR、不生成解析，主流程没有它也能用。

## 边界与决策

- **只读已在错题本里的题**（v1 构想 F8）：详情页打开时后台请求，不阻塞题目/解析显示。
- **纯正则 + 规则**，不接云端 AI。OCR 只复用本机 RapidOCR；识别结果和候选都留在本地。
- **不写用户库**：分析结果缓存在 `.cache/answer_ocr/<qid>.json`，不进 `data/`、不进备份。
- **不做自动打标**：候选只是勾选提示，必须点一下 + 保存才生效；没证据就不猜。
- Z 族读**遮罩后的答案半页**（`_ma`），和复习流程看的是同一块内容；拆分失败才退回整页。

## 抽条文（`app/answer_ocr.py`）

- 先把 OCR 行拼成一个无空白字符串再匹配，解决标题跨行（`《建筑地基基` + `础设计规范》`）。
- 每条《…》记录标题、标准号、条文号；同一本书在题干和点评各出现一次时按标题合并。
- 已覆盖的真实写法：
  - `《建筑地基基础设计规范》GB50007-2011第5.2.6条，附录J`
  - `《建筑桩基技术规范》(JGJ94-2008)`（括号里的标准号）
  - `《岩土工程勘察规范》第3.2.2条，第14.2.2~14.2.4条`（范围不拆成两条）
  - `《湿陷性黄土地区建筑标准》2.1.7、4.3.4及条文说明、4.4.1`
  - `《水运工程岩土工程勘察规范》p81页第14.7.4.5条`（页引用后再跟条文号）
- 只有标题、没有条文/标准号的提及（`未指定《土工试验方法标准》时…`）会显示在依据里，
  但**不单独触发「规范错」候选**。
- 候选规则：条文号 ≥1 → 「规范错」（带完整依据）；点评里出现「注意/仔细/看清/忽略…」
  → 「审题错」；「计算量/细心计算/换算/代入…」→ 「算错」；「概念/定义/原理…」→ 「不会」。
- 点评范围优先取最后一个 `【点评】`；没有点评才看 `【解析】/【解答】` 的尾部，
  避免把解答里的普通「计算」当成提示。
- 最多 3 个候选，点评提示排在纯依据前面。

## 接口与页面

- `GET /api/attempts/{id}/suggest`：同步跑裁图 + OCR + 分析，返回
  `citations / candidates / cached / seconds / elapsed_ms`。
  裁图或 OCR 失败时返回 200 + `error`，详情页照常可用。
- 错题详情页在标签下方新增「错因建议」面板：先显示依据，再显示候选 chip 和触发句子；
  点候选 = 勾选上方对应错因，仍需点「保存」。面板加载中不影响图片和已有标签。
- 缓存键 = 裁图路径 + 大小 + mtime + `CACHE_VERSION`；裁图重建或规则升级自动失效。

## 二轮（同日）：复习面板接入 + 规范候选降噪

- **复习「没做对」面板接候选**：点「看答案」后，答案下方出现同一个「错因建议」面板；
  点候选 = 勾选上方同名错因，评分时随「没做对」一起入库。面板与详情页共用
  `suggestionUI / renderSuggest / loadSuggest`，只是各自读写自己的标签集合
  （详情 = 已存的标签 chip，复习 = `state.review.tags`）。
  - 翻题 / 撤销时面板立即隐藏并作废在途请求（token + 当前 qid 双保险）；
    首次读 3–6 s 不阻塞看答案与评分。
- **规范候选降噪**：只有**≥2 部规范**，或**没有其它候选**时，才给「规范错」。
  单部规范 + 点评易错句 → 只给审题/算错/概念（此前 5 题属于这类噪声）。
  - 29 题基准：有候选仍 **24/29**；`standard` 23 → **18**，其余 calc 3 / misread 3 / concept 2。
  - `CACHE_VERSION` 2 → 3，旧缓存自动失效。
- **验证**：75 条单测全绿；headless Chrome（CDP）走真实服务 + 临时库：
  - 复习 C4-15：缓存 2 ms 出 `calc+concept`，点候选 → `state.review.tags` 与标签 chip 同步，
    评「没做对」→ 错题行 tags 落库、游标前进；
  - 详情 C3-11：缓存 0–10 ms 出 `standard`，点候选与已存标签双向同步（再点即取消）；
  - 截图存 `.probe/m4r2_e2e/`（不入库）。
- 页面角标 M3 → M4。

## 有意没做 / 已知缺口

- OCR 读不出的题（如 M33-2）没有二遍重试；空结果就是空结果。
- 首次读解析 2–6 s，没有预取；同一题第二次打开走缓存。
- 候选只解释「解析怎么说」，不判断用户实际错在哪；「不会」类证据仍偏少。
- 复习面板不区分「做对了」——评分做对时标签本来就不入库，候选只是提示。
