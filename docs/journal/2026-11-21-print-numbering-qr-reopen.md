# 打印页码分两套 + 扫码入口更显眼

2026-11-21 · 打印 / 手机接入

## 需求（_ming）

1. 每天打印的卷：**题面和解析面分开编页码**。
2. 二维码要有一个按钮随时点开；中途关掉卡片后不知道去哪儿扫码。

## 决定

1. **页码按区各从 1 起。** 题面 `题面 第 k/Q 页`，答案 `答案 第 k/A 页`；
   Q / A 只数实际印出的题页和答案页。总封面和周包的每日小封面不编号、不占号。
   理由：答案页是封存后单独使用的，混进题面的总页码会让人误以为缺页或拿错半卷。
2. **按钮改名「扫码」，关闭自动弹出的卡片时提示位置。** 原按钮叫「手机」，
   不容易联想到二维码；`?qr=1` 自动弹出后一旦收起，入口在视觉上就消失了。
   现在关闭时会 toast「二维码随时可点顶部「扫码」重新打开」，只提示一次。
   设置页「显示二维码」入口保留，窄屏（≤760px）顶部仍隐藏——手机自己不需要扫自己。
3. **不改打印顺序和封面。** 题面在前、答案在后、封面不编号的既有规则不动，
   只换页脚编号方式。

## 实现

- `app/print_export.py::_stamp`：先按 `answer_from` 把要盖章的页分成题面/答案两组，
  各自 `enumerate(..., 1)`；跳过封面页。
- `app/static/index.html`：顶部按钮「手机」→「扫码」；新增 `closePhoneSheet()`，
  自动打开时记 `phoneAutoHint`，关闭时提示一次；点遮罩也走同一函数。
- `tests/test_print_export.py`：mixed 卷断言题面/答案各自从 1；新增 `_stamp`
  纯逻辑测试（封面空、题面 1/2、答案 1/2）。
- 文档：`docs/usage.md`、`README.md`、`docs/SUMMARY.md` 同步按钮名和页码规则。

## 验证

- `py -3 -m pytest -q` → **392 passed**（原 391 + 新增 1），10 subtests 通过。
- `tests/test_print_export.py` 5 条全绿；真实裁剪卷页脚文本含 `题面 第 1/…`、
  `答案 第 1/…`。
- 无头 Edge + CDP（Node WebSocket）实点：
  - 打开 `?qr=1` 卡片自动弹出，默认地址 `https://your-machine.your-tailnet.ts.net/?v=…`；
  - 按钮文本「扫码」；
  - 点「收起」→ 卡片隐藏，toast 显示「二维码随时可点顶部「扫码」重新打开」；
  - 点顶部「扫码」→ 卡片重新打开，地址不变。
- 内联 JS `node --check` 通过。
