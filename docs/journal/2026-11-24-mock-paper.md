# 整卷模拟：把「偏题 + 时间紧」变成三个可测的数字

2026-11-24 · 计划 / 考场推演 / 2026 考点分布

## 需求（_ming）

2018–2026 每年都有难题、偏题，考场上时间紧，这些题很难解决。
_ming 自己的感受：一遇到没做过几遍的题就陌生，费时还做不对。
2026 两卷 PDF 里带讲解分析，能用就用。

## 先算账：偏题不是要解，是要识别

- 50 题 × 2 分 = 100，60 分过线，**允许错 20 题**。
- 360 分钟 / 50 题 = **7.2 分钟/题**；一道偏题耗 20 分钟换 2 分，
  机会成本是 2.8 道常规题（5.6 分），净亏。
- 2025 基线：13 道超时题全做对，平均 10.6 分钟/题——
  慢在会做的题上，不是慢在不会的题上。
- 结论：**偏题的价值是「用最低成本确认它不值得做」**，不是做出来。

## 2026 PDF 给了唯一一份逐题标注

两卷「考点分布」页（上午第 4–5 页、下午第 4–5 页）每道题都有：

    考点 | 答题依据 | 频率（偏/常规/灵活）| 计算量（小/中/大）| 难易（易/中/难）

纯扫描无文本层，用 RapidOCR 按 token 的 x 坐标还原列
（上午与下午版心不同，各用一套列边界）。结果：

- **上午 25 题：偏 9、常规 16**
- **下午 25 题：偏 4、灵活 7、常规 14**——与华山原文「下午有少量偏题，4 个
  （D01/D04/D15/D16）」逐题吻合。

这是 2018–2025 没有的（那些年份只有规范引用可提取，没有逐题难度标注），
所以 2026 作为偏题识别的训练卷和验证卷最合适。

## 决定

1. **新功能独立于「整卷复测」。** 复测只记四个数；整卷模拟逐题记
   `标记 A/B/C + 实际用时 + 结果`。两者互不写台账，避免污染基线。
2. **每题两个动作，不做题号跳转。** 真实考试按顺序做：`做完了` 记用时进下一题，
   `跳过` 自动记 C + skipped。标记按钮只决定「这题值不值得做」，不判对错。
3. **复盘只看三件事**，每条都带数字：
   - A 判断准不准：标 A 的题做对率 < 80% → A 标得偏乐观；
   - 该跳没跳：标 C 且投入 > 8 分钟 → 列出题号和烧掉的分钟数，换算成常规题数量；
   - 偏题识别率：2026 标「偏」的题里，标 C 或跳过的比例；未接触的题不算分母。
4. **7.2 分钟是预算，8 分钟是硬停。** 两个都有：超预算列表看节奏，
   超硬停列表看纪律。
5. **2026 数据只做「复盘参照」，不做评分。** 案例是人工按过程评分，
   不按选项字母；模拟分数 = 做对数 × 2，仅作节奏参考。

## 实现

- `tools/build_exam_levels.py` → `index/exam_levels.json`：
  上午/下午各 25 题，OCR 结果缓存 `.cache/exam_levels/`，可重跑。
- `app/mock.py`：25 题生成、动作校验、复盘统计、建议、2026 偏题对照。
- `app/store.py`：`mock_runs` / `mock_items`（schema 11 → 12）。
- `app/server.py`：8 个 `/api/mock*` 路由。
- `app/static/index.html`：计划页卡片 + 全屏计时面板 + 复盘面板；
  刷新后可「继续」，总时长按服务器 `started_at` 算，不依赖浏览器计时器。

## 验证

- **20 条新单测**：建卷/跳过强制 C/字段校验/预算与硬停/该跳没跳/误跳/
  A 标记正确率/偏题分母不含未接触题/完成删除/批量回填。
- **全量 428 条全绿**（schema 版本断言同步升到 12）。
- **CDP 无头 Chrome 14 项 PASS**：面板渲染 → 开始 → 标 A 做一题 → 跳过一题 →
  进度格 → 结束 → 复盘 25 行 → 回填两题 → 分数 2/50 → 计划页列表 → 0 console 错误。
