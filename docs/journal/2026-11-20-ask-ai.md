# 问 AI：每道题都能追问，但答案必须落在解析和条文上

2026-11-20 · AI + UX

## 需求（_ming）

做 A2025-A-9 时不明白「摩擦型桩中性点以上的摩阻力不计入」，
以及「承台下那 1m 非液化层为什么不计」；希望做题时能直接问 AI，
最好手机上还能语音。

## 决定

1. **不是通用聊天，是「问这一题」。** 打开面板时自动带：题干 OCR、官方解析 OCR、
   M11/M4 匹配的规范条文（条号 + 精确页原文）、用户的问题。80% 的价值在上下文拼装。
2. **只发文本，不发原图。** DeepSeek 是文本模型；题图在电脑上用 RapidOCR 转文字，
   默认不发照片、不发错题本全量。图里的层厚/尺寸识别不全时，
   prompt 要求「以解析的取法为准」，不许重新从 OCR 图推断条件。
3. **回答要有来源。** 固定结构：疑点 → 依据（解析步骤/条号）→ 易混点 → 回到本题；
   条号用本机规范索引复核，查不到标「未核对」；整个回答标「AI 解读」。
   不判分、不改复习排期、不自动打错因。
4. **入口不剧透。** 复习页的「问 AI」在点过「看答案」之后才出现；错题详情、
   查题查看器直接可问。纸卷深链 `/?qid=…&ask=1` 先留着，后面接封面二维码。
5. **钱和 key 都留在电脑。** 手机只请求本机 FastAPI；本机再调 DeepSeek。
   key 在 `data/llm.json`（data/ 已 gitignore），不进仓库、不进备份 zip。
   默认每天 20 次上限；相同问题 + 相同上下文 30 天缓存，缓存命中不占额度。
6. **语音分两步。** 本版用手机输入法麦克风（面板有提示）；网页内按住说话
   需要 HTTPS secure context，等 Tailscale Serve 版再做，不先用自签证书。

## 实现

- `app/qa.py`
  - `load_config`：`data/llm.json` + `YANTU_LLM_*` 覆盖；`public_config` 不返回 key。
  - `build_context`：裁图签名 + hints 哈希缓存 `.cache/qa/<qid>.json`；
    本地 OCR 题干/解析；从解析 OCR 自动补 M4 没抓到的条号（这次补上了 5.3.12）。
  - `clause_text`：先用 `locate_clause` 找节起点，再在文字层里向前搜条号，
    找到**精确页**（5.3.12 → PDF p29），读该页 + 下一页；扫描件只留页码。
  - `build_messages`：system prompt + 材料 + 最近 6 条对话 + 新问题。
  - `chat`：OpenAI 兼容 `/chat/completions`，默认 DeepSeek；
    401/402/429/超时分别给人话错误，错误信息里抹掉 key。
  - `ask`：先查缓存 → 再查额度 → 调模型 → 复核条号 → 落库。
  - `verify_citations`：`《规范》第x.y.z条` 与 `JGJ 94-2008 第x.y.z条`
    都解析；本地规范索引查不到就计入 warnings。
- `app/store.py`：schema 11 新增 `qa_threads` / `qa_messages`；
  `qa_history` / `qa_add_exchange` / `qa_cached` / `qa_calls_today` / `qa_clear`。
- `app/server.py`：`GET /api/qa/{qid}`（记录/额度/条文预览，不 OCR、不花钱）、
  `POST /api/qa/{qid}/ask`、`DELETE /api/qa/{qid}`。
- `app/static/index.html`：底部「问 AI」面板（来源 chips、预设问题、线程、
  配额、键盘麦克风提示）；入口在复习页答案后、错题详情、查看器；
  深链 `?qid=…&ask=1`。

## 验证

- **pytest 372 条全绿**（新增 10 条：schema、缓存/额度、配置隐藏 key、
  上下文缓存、prompt 拼装、条号复核、fake provider 的额度/缓存/超限）。
- **真实库副本 + 本地 stub provider 端到端**：context 6,570 字，
  含题干 OCR、解析 OCR、5.3.12 条文；第一次提问 `used=1`，第二次相同问题
  `cached=true` 且仍 `used=1`、stub 只被调用 1 次；历史 4 条。
- **真实 DeepSeek 冒烟 2 次**（A2025-A-9，题干+解析+条文）：
  - 第 1 次 4,548 prompt + 454 completion token，回答结构正确，但把「承台底以上
    非液化土」说少了；据此加了规则 8（解析口径优先，不许重推 OCR 图）并加 `PROMPT_VERSION`。
  - 第 2 次 4,644 + 356 token，回答正确：负摩阻力方向、5.3.12 折减、
    「承台下 1m 是适用条件，不是把土本身扣掉」；无未核对引用。
  - 合计约 1 万 token，约 ¥0.01–0.02；真实库 `used_today` 仍为 0（冒烟在临时库）。
- **无头 Edge 深链** `/?qid=A2025-A-9&ask=1`：面板打开、3 条规范 chip、
  「今日 AI 0/20」、发送键可用、预设问题与麦克风提示都在；JS 语法检查通过。
- 真实库只做了 schema 11 迁移，没有写入问答；服务已重启。

## 限制 / 下一步

- DeepSeek 没有视觉：图/表/层厚只能靠 OCR 文本；OCR 丢条件时以解析为准，
  但仍可能讲错。界面已标「AI 解读，以原文为准」。
- 首次问一题要 OCR 约 10 s + 模型 10–20 s；同题后续走上下文缓存。
- 语音只有键盘麦克风；网页内按住说话要 HTTPS（Tailscale Serve），
  之后音频上传到电脑做 ASR（百炼或本地 Whisper）。
- 纸卷二维码、按原型横向比较、把回答存成错题笔记，留到 v1.5。
