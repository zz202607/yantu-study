# 规范伴读

状态：M10 · 2026-11-03（2026-11-17 增手边翻页与真题足迹）

## 目标

把「读规范」从通读整本，变成按考试权重排好的短路线：

```
选规范 → 一站（6–18 分钟）→ 看标注版原页 → 读「为什么考/先看什么/易错点」
       → 合上页面自检 → 做一组同类题 → 下一站
```

每一站只解决一个问题。不重写教材，不生成规范正文；页面永远是原书扫描页，
红色旁注和下划线保留，解释只做导航和提醒。

每站包含：

- `why`：这一节为什么考、对应哪个原型；
- `look_for`：先看哪几条/哪张表；
- `pitfall`：最常见的错法；
- `check`：合上页面后的 30 秒自检；
- `clauses`：可点击的条文号（走现有 `standards/locate`）；
- `practice`：原型题号区间，点开直接看题；
- `page`：印刷页；标注版页码由构建工具解析。
- 阅读页下方可「上一页 / 下一页」翻标注版原 PDF，不只停在一站的第一页；
  像「5.3 变形计算」这种跨页小节，可以直接翻到 5.3.5 所在页。

## 精读模式（2026-11-16）

多数标注版每页是**同一印刷页的左右两联**（2-up）：直接看整张图，字号只有一半。
**GB 50011 例外**：它是竖版单页扫描，不能裁切。服务端按 PDF 页面宽高比自动判断，
横版才裁单联、竖版保持整页；客户端无脑带 `half=left` 也不会裁掉内容。
阅读站现在拆成两层：

1. **行内页**：默认只渲染左联（`half=left`），字号翻倍；点图或「全屏精读」进入精读。
2. **精读模式**（`#readRoom`，全屏浮层）：
   - 左栏是「目录 + 要点」：站下拉（可跳任意一站）、为什么读、先看这些、
     条文 chips、最容易错、30 秒自检、同类题、笔记、需回看 / 看完了；
   - 右栏是规范原页：220 dpi 单联、默认按宽度铺满（纵向滚动，字最大），
     「整页」切全局视野；可 `+ / −` 缩放、拖动平移、双击放大；
   - 翻页：`← / →`、`PgUp / PgDn`、工具栏上下页和跳页；翻的是整本标注版，
     不局限于一站；
   - **手边翻页（11-17）**：页面底部常驻浮动翻页条（44px `‹ / ›` + 页码），
     桌面 hover 页面两侧出边缘热区；宽度铺满时滚轮先滚页、到页底继续滚才翻页，
     触控板横向滑动直接翻；手机左右滑，`Space / Shift+Space` 也可翻。
     顶栏页控件在 <620px 收起，避免和翻页条重复；
   - 上下站：顶部 `‹ / ›` 或左栏下拉；`Esc` 退出精读。
   - 手机（<900px）：左栏变成「要点」抽屉，页面占满宽度，字号与桌面一致；
     右侧真题栏隐藏，题号仍出现在「要点」抽屉里。

## 真题足迹（2026-11-17）

伴读站、精读右栏和阅读路线行都会标出**真题考察的年份和题号**，例如
`2024上午6 · 2024 年上午第 6 题 · 引用第5.2.7条 · 答案解析`。

数据不是人工回忆，而是离线 OCR 索引：

- `tools/build_exam_refs.py` 遍历 `lookup.json` 里有题面页与答案页的案例真题
  （A 族，2012–2025；2015 年停考）；先 OCR 答案解析（解析会写依据规范），
  解析没有引用时再 OCR 题面；2025 两卷直接读 `index/tags/` 的机器文本。
- 只收录能在本机 50 本规范索引里精确解析的《规范》标题/标准号；条文号能读出来
  就保留，读不出就只记到规范级。**解析不出来的不猜、不补。**
- 输出 `index/exam_refs.json`，按题存；断点续跑，每 10 题原子落盘：

```bash
PYTHONIOENCODING=utf-8 py -3 tools/build_exam_refs.py            # 全量续跑
PYTHONIOENCODING=utf-8 py -3 tools/build_exam_refs.py --year 2024,2025
PYTHONIOENCODING=utf-8 py -3 tools/build_exam_refs.py --limit 6   # 试跑
```

展示规则：

| 位置 | 内容 | 归位依据 |
|---|---|---|
| 站页「真题足迹」 | 本站命中 + 可展开的整本历年真题 | 条文号落在本站条文/节 |
| 精读右栏 | 本站题号；本站无条文号时显示整本最近 8 题 | 同上 |
| 阅读路线行 | `真题 n` 徽标 | 同上 |

- 没有条文号的引用只出现在**规范级**，不会被塞进某一节。
- 点题号：桌面新开 `/?qid=A2024-A-6` 标签页（精读不关闭），手机走应用内查看器。
- 区块里写明「只收录解析或题面明确引用的真题」与索引覆盖率；没查到 ≠ 没考过。
- 只索引案例真题；知识真题 K 族与模拟题尚未进索引。
3. **页图接口**：`GET /api/reading/{code}/{stop}/page?dpi=220&half=left&p=22`。
   `half` 只作用于横版 2-up 标注版；竖版单页（GB 50011）与干净版回退都会忽略 `half`，
   不会把正常单页裁掉。版式按 PDF 页面宽高比检测，并按文件 mtime 缓存。
   - `/api/reading/{code}` 的 `annotated.two_up` 把同一判断返回给前端；
     前端只对 `two_up=true` 的书带 `half=left`。竖版书的 URL 因此不带该参数，
     旧版本缓存的「半页图」（同 URL、24h 缓存）会被自然击穿，不用用户清缓存。
   dpi 上限从 200 提到 300；页缓存按 `p<页>_<dpi>_<l|r>.png` 分开。

### 标注版为什么需要单独建索引

`E:\其他文件\2025YT\4标注版核心规范` 里的 PDF：

- 没有文字层，也没有 PDF annotation；红色标注是扫描进画面的；
- 多数书每一页是**同一印刷页的左右两联**（2-up），不是连续两页；
  GB 50011 是竖版单页（8/9 本横版 2-up），页索引逻辑对两种版式都适用；
- 书前目录页也印着 11、12…，会与正文页号重复。

所以不能直接用 `printed_page + offset`。构建工具的做法：

1. 抽样 OCR 页脚，得到 `PDF 页 → 印刷页` 的单调锚点；
2. 用正文与目录页的页码偏移差，识别 `content_start`，丢掉目录页锚点；
3. 用锚点线性插值每一站的 PDF 页；
4. 在估计页附近 OCR 校验；OCR 失败时保留插值页并标「估」。

重建：

```bash
PYTHONIOENCODING=utf-8 py -3 tools/build_annotated_index.py
PYTHONIOENCODING=utf-8 py -3 tools/build_annotated_index.py --only "GB 50007"
PYTHONIOENCODING=utf-8 py -3 tools/build_annotated_index.py --force
```

`--force` 会重做未变化的文件；正常重跑会复用已建好的路线。

## 进度与推荐

- 每站两种状态：`done`（已读）和 `review`（需回看）；回看站优先于未读站。
- 每次保存追加一条 `reading_log`，记录本次秒数；`reading_progress.seconds` 累计。
- 推荐顺序：最近读过的规范 → 它的下一站；没有记录时按路线顺序从抗震开始。
- 首页卡片显示「已读 n/67 站、本周分钟、下一个站」，点击直达当前站。
- 深链：`/?tab=data&view=reading&code=GB50007-2011&stop=gb50007-5-2`。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/reading` | 路线、进度、本周统计、下一站推荐、每本真题数 + 索引覆盖率 |
| GET | `/api/reading/{code_key}` | 单本规范路线 + 每站状态/标注版页 + 每站真题足迹 |
| POST | `/api/reading/{code_key}/{stop_id}` | `{status, seconds, note}` 保存一站 |
| GET | `/api/reading/{code_key}/{stop_id}/page` | 标注版页图；`p` 翻页、`dpi=80..300`、`half=left|right` 裁单联；缺页时回退干净版（忽略 `half`） |
| GET | `/api/reading/{code_key}/file` | 打开标注版 PDF |

## 边界

- 不复制、不上传规范；只在本地读 `E:` 盘，App 只存路径与页码。
- 标注版目录不在线时，页图回退到 `3注册岩土全套电子版规范` 的干净版；
  两边都不在线时只显示路线文字，不影响错题本。
- 内容只覆盖 9 本高频规范；其余规范仍走「规范地图 + 章节索引」查。
- `estimated` 页是插值结果，读的时候以页眉的印刷页号为准。
- 不做 AI 生成解析；解释是静态、可复核的导航文本，原文永远在页面上。
