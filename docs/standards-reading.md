# 规范伴读

状态：M10 · 2026-11-03

## 目标

把「读规范」从通读整本，变成按考试权重排好的短路线：

```
选规范 → 一站（6–18 分钟）→ 看标注版原页 → 读「为什么考/先看什么/易错点」
       → 合上页面自检 → 做一组同类题 → 下一站
```

每一站只解决一个问题。不重写教材，不生成规范正文；页面永远是原书扫描页，
红色旁注和下划线保留，解释只做导航和提醒。

每站包含：

- `why`：这一节为什么考、对应哪个原型；
- `look_for`：先看哪几条/哪张表；
- `pitfall`：最常见的错法；
- `check`：合上页面后的 30 秒自检；
- `clauses`：可点击的条文号（走现有 `standards/locate`）；
- `practice`：原型题号区间，点开直接看题；
- `page`：印刷页；标注版页码由构建工具解析。
- 阅读页下方可「上一页 / 下一页」翻标注版原 PDF，不只停在一站的第一页；
  像「5.3 变形计算」这种跨页小节，可以直接翻到 5.3.5 所在页。

### 标注版为什么需要单独建索引

`E:\其他文件\2025YT\4标注版核心规范` 里的 PDF：

- 没有文字层，也没有 PDF annotation；红色标注是扫描进画面的；
- 每一页是**同一印刷页的左右两联**（2-up），不是连续两页；
- 书前目录页也印着 11、12…，会与正文页号重复。

所以不能直接用 `printed_page + offset`。构建工具的做法：

1. 抽样 OCR 页脚，得到 `PDF 页 → 印刷页` 的单调锚点；
2. 用正文与目录页的页码偏移差，识别 `content_start`，丢掉目录页锚点；
3. 用锚点线性插值每一站的 PDF 页；
4. 在估计页附近 OCR 校验；OCR 失败时保留插值页并标「估」。

重建：

```bash
PYTHONIOENCODING=utf-8 py -3 tools/build_annotated_index.py
PYTHONIOENCODING=utf-8 py -3 tools/build_annotated_index.py --only "GB 50007"
PYTHONIOENCODING=utf-8 py -3 tools/build_annotated_index.py --force
```

`--force` 会重做未变化的文件；正常重跑会复用已建好的路线。

## 进度与推荐

- 每站两种状态：`done`（已读）和 `review`（需回看）；回看站优先于未读站。
- 每次保存追加一条 `reading_log`，记录本次秒数；`reading_progress.seconds` 累计。
- 推荐顺序：最近读过的规范 → 它的下一站；没有记录时按路线顺序从抗震开始。
- 首页卡片显示「已读 n/67 站、本周分钟、下一个站」，点击直达当前站。
- 深链：`/?tab=data&view=reading&code=GB50007-2011&stop=gb50007-5-2`。

## 边界

- 不复制、不上传规范；只在本地读 `E:` 盘，App 只存路径与页码。
- 标注版目录不在线时，页图回退到 `3注册岩土全套电子版规范` 的干净版；
  两边都不在线时只显示路线文字，不影响错题本。
- 内容只覆盖 9 本高频规范；其余规范仍走「规范地图 + 章节索引」查。
- `estimated` 页是插值结果，读的时候以页眉的印刷页号为准。
- 不做 AI 生成解析；解释是静态、可复核的导航文本，原文永远在页面上。
