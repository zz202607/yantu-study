# 客观题记分（知识题）与案例题边界

状态：M5.1 · 2026-11-02

## 一句话

**知识题是客观题，可以用字母判分；案例题是主观题，只能按过程人工判分。**
两者不得共用一套判分逻辑。

## 为什么单独拆开

- 专业案例（第二天，上午/下午各 25 题）要求写出计算过程；**只有答案没有过程按 0 分**，
  过程与结果都要对才算做对。题面不是 A/B/C/D。
- 华S 资料把部分案例题排版成带选项的练习题（例如 `1.【答案】（C）`），那是**资料书的
  选项核对**，不是考试评分规则。任何代码都不能拿这个字母回判案例。
- 专业知识（第一天）是 40 单选 + 30 多选 × 2 场；多选错选/多选/少选均不得分，
  适合用客观题模块精确集合匹配。

## 知识题模块

代码：`app/objective.py` · CLI：`tools/score_objective.py`

答案键格式：

```json
{
  "paper": "K2025-A",
  "questions": [
    {"qid": "K2025-A-1", "type": "single", "answer": "B",
     "points": 1, "category": "勘察"},
    {"qid": "K2025-A-41", "type": "multiple", "answer": ["A", "D"],
     "points": 2, "category": "浅基础"}
  ]
}
```

作答文件可以是 `{"K2025-A-1": "B", "K2025-A-41": "AD"}`，也可以是按题序的列表。

```bash
PYTHONIOENCODING=utf-8 py -3 tools/score_objective.py \
  --key path/to/key.json --answers path/to/answers.json
```

规则：

- 单选：只允许一个字母；多选：集合完全相等才算对。
- 空白、少选、多选、错选均为 0 分。
- 按类别汇总题数、作答、答对、得分。
- **不内置任何案例答案键**；不要把 `index/tags/A2025.json` 喂进来。

## 案例题模块

- 复习时由用户选择：`过程对 · 结果对` / `过程对 · 结果错` / `过程错` / `没思路`。
- 可拍一张手写过程照片，随评分入库；详情页可回看。
- 基线只记录四个数：作答题数 / 做对数 / 放弃数 / 超时题数；
  做对 = 过程与结果均正确。主入口：网页「计划 → 2025 案例基线」；
  `tools/score_baseline.py` 仅作电脑端回填。
- 代码永不根据选项字母自动判定案例对错。

## 数据边界

| 用途 | 数据 | 判定方式 |
|---|---|---|
| 知识真题/习题（Z/K） | 客观题答案键 | 字母/集合精确匹配 |
| 案例习题/真题/模拟（C/A/M） | 用户过程状态 + 过程照片 | 人工选择 |
| 2025 案例基线 | 四个数 | 人工按过程自评 |
| `index/tags/A2025.json` | 资料书选项键 | **仅作题号/类别/资料核对，不用于判分** |
