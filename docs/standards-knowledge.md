# 规范与知识点 · 想法草案（v1.5+）

状态：构想稿（未写代码） · 2026-10-31
前置：v1 先把「拍错题 → 复习 → 打印」跑通；本文件只讨论规范与知识点，不进入 v1 范围。

---

## 0. 两个核心判断

1. **规范不是拿来通读的，是查资料时的定位工具。**
   真正要练的是：看到题 → 知道翻哪本 → 找到哪条 → 用对条件。
   把整本规范读一遍，投入产出很低。
2. **知识点总结不要重写教材，只总结你已经错过的。**
   书上的【解析】【点评】本身已经是高质量总结；用原图、原文、原条文，
   不做 AI 生成，避免幻觉，也避免额外整理工作。

这两条决定了后面的所有设计：**接依据、练定位、做个人卡，不做通用教材。**

## 1. 规范

### 1.1 规范登记表（低成本，先做）

- 现有 50 本规范 +《工程地质手册（第五版）》+ 2 张区划图，共 51 个 PDF、约 1.3 GB。
- 为每个 PDF 建一条元数据：编号、规范名、标准号、年份、页数、
  **是否有文字层**、是否有目录、文件路径。
- 不复制、不压缩、不重命名原件；App 只存路径。
- E: 盘未连接时降级：只显示规范名/条文文字，不提供跳转，不影响错题本。

### 1.2 从解析里抽「依据」（最高性价比）

只对**已加入错题本**的题做，不碰全库：

- OCR 答案裁图，抽取 `《规范名》 + 条文/表/附录/公式号`。
  例：`根据《建筑地基基础设计规范》5.2.1`、`查表 D.0.2`、
  `《岩土工程勘察规范》GB 50021-2001 第 3.3.8 条`。
- 用 51 本规范名/标准号做**封闭词表**做纠错匹配；比自由 OCR 可靠得多。
- 产出：`qid → [规范, 条文, 页码（尽力）]`。
- 错题详情显示「依据」chips；点击打开规范原文（精确跳转或目录页）。
- 打印卷的解析页加一行「依据：GB 50007-2011 §5.2.1」，方便回查。
- 规范缺失/版本不符：保留文字，标「未收录」，不阻塞。

**为什么先做这个：** 它把你已有的错题和已有的规范直接接上，
不需要新增任何整理动作，却能让每道错题都指向可回查的原文。

### 1.3 规范定位训练（规范部分的第一优先级）

只针对 `规范错` 的题，**不做完整重算**，做 30 秒定位训练：

1. 看题 → 自问「考哪本规范？」
2. 再问「哪一条 / 哪张表？」
3. 展开依据 → 打开原文对应位置。

训练的是考试真正用到的动作：**定位**。比重做一道 8 分钟的案例高效得多。

- 可选记录定位用时/命中率，周报显示趋势；不做排行榜。
- 依据缺失时：用章节→规范的大致映射提示，或跳过。
- 这个模式可以和「今日复习」混排：`规范错` 出定位卡，`不会` 出知识卡，`算错` 出重做。

### 1.4 依据视角

- **我的依据索引**：按规范/条文聚合错题——哪本规范你错得最多、哪条反复出现。
- **考前依据清单**：把错题里出现过的条文去重，打印 1–2 页；
  考前翻这个，不复读整本规范。
- **规范地图（可选）**：按主题把 50 本分成 勘察 / 地基 / 桩基 / 边坡 / 基坑 /
  抗震 / 检测 / 铁路 / 公路 / 水运 等，一页纸；只列规范名 + 标准号 + 你最常错的条文。
  不复制正文；对开卷考试很实用，但优先级低于 1.3。

### 1.5 规范全文搜索（P3，不急）

- 有文字层的规范：本地全文索引（SQLite FTS5）；没有文字层的：按需 OCR 单页。
- 不做全量 OCR 51 个 PDF；先做「已引用条文」的页码缓存，再考虑全文搜索。
- 不自己实现 PDF 阅读器；调用系统/现有 PDF 打开到页即可。

### 1.6 规范部分的边界

- 不复制、不上传规范；仅本地个人使用。
- 不追求每条都精确跳到条文：文字层可精确搜索；扫描件先开目录/邻近页，再人工定位。
- 不把 50 本规范做成知识库网站；它是一个「依据跳转层」。

## 2. 知识点

### 2.1 三层总结，越往下越省事

1. **单题一句话教训**（可选，5–10 秒）：这题我错在 __。
2. **章节知识卡**（自动聚合）：一章一页，来自你的错题与解析点评。
3. **考前 one-pager**（打印）：只保留最弱的 3–5 章 + 你的高频依据。

### 2.2 章节知识卡（v2）

每章一页，自动生成框架，用户可改：

- 本章错题 N / 已掌握 M；四类错因分布。
- 高频依据：Top 3 规范条文（来自 1.2）。
- 最近 3 道错题缩略图 + 每道的一句话教训。
- **本章最该记住的 3 个坑**：从【点评】OCR 出的关键词/句子，
  保留原图引用，不重写。
- 快捷动作：复习本章错题 / 打印本章一页纸 / 打开相关规范。
- 本章错题 < 3 时不生成空卡，避免形式主义。

### 2.3 四类错因 → 四种复习动作

这张表就是「有效复习」的核心：不同错因，用不同动作，别都用「再做一遍」。

| 标签 | 不要这样做 | 应该这样做 |
|---|---|---|
| `不会` | 反复看解析 | 先看本章知识卡/对应小节，再做 1–2 道同类题 |
| `算错` | 重学概念 | 限时计算 + 单位/代数检查清单；只重算错的那一步 |
| `规范错` | 重做整道案例 | 30 秒定位训练：哪本、哪条、哪个表 |
| `审题错` | 盲目多刷 | 审题清单（埋深/水位/组合/单位/问法），先圈条件再算 |

### 2.4 知识卡的形式

- **图像优先**：公式、表格、图从原书/规范裁图，不重写成文字；避免 OCR 公式出错。
- **一页封顶**：卡片长了就没人看；一页只放「你的错 + 依据 + 1 个动作」。
- **个人化**：没有你的错题，就不生成这一章；不做通用教材摘要。
- **可编辑**：自动聚合 + 你补一句话；不追求全自动正确。
- **主动回忆**：卡片是「查」的，不是「读」的；复习仍以做题为主。
- **不做讲义**：如果以后要主题总结，只生成骨架（章节标题 + 你的错题 + 依据），
  正文由原书、原解析、原条文提供，不写长篇教材摘要。

### 2.5 考前冲刺包（v2.5）

- 弱章 one-pager（3–5 页）。
- 错题重做卷（题面 + 留白 + 答案分离）。
- 依据清单（去重后的条文/表）。
- 全部来自你的错题数据，不新增整理动作。

## 3. 优先级

| 阶段 | 做什么 | 为什么 |
|---|---|---|
| v1 | 不做规范/知识卡；只保留章节名与可选笔记 | 先把错题闭环跑通 |
| v1.5 | 规范登记表 + 依据抽取 + 打开原文 + 规范错定位训练 | 最高性价比，直接服务考试 |
| v2 | 章节知识卡 + 个人一页纸 + 我的依据索引 | 把错题变成个人知识地图 |
| v2.5 | 条文级跳转、全文搜索、冲刺包、定位计时 | 锦上添花 |
| 不做 | 全量 OCR 51 个 PDF、AI 生成总结、自写 PDF 阅读器、知识图谱 | 成本高 / 幻觉 / 偏离核心 |

## 4. 待确认的假设（不阻塞）

- 考试中规范是否可查：按「可查」设计；若某科闭卷，就把比重从定位训练移到知识卡。
- E: 盘是否长期在线：不在线时 App 降级，不影响错题本。
- 打印卷是否带规范条文原文：默认只带「依据行」，需要时再加条文摘录（个人使用）。

## 5. 一句话总结

**先把「依据」接回错题，再练「定位」，最后才做「总结」。**
顺序反了，就会变成读规范、抄教材——很努力，但不提分。

## 6. M10 补充：伴读不是通读

2026-11-03 增加了「规范伴读」：9 本核心规范、67 站，每站 6–18 分钟。
它仍然遵守上面的边界：

- 不重写条文，页面就是标注版原页；解释只做导航和易错提醒。
- 不按页通读，按考试原型和条文位置排短路线；每站有明确的「看完 / 需回看」。
- 不做通用教材：没有错题、没有考试权重的规范章节不排进来。
- 原文永远优先：`estimated` 页或 OCR 噪声都以页眉印刷页号为准。
